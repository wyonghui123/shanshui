# D2 · 意象—画法映射表

> **一句话**：给全链路一张「意象类别 → 三远/皴法/墨色/含水/笔法/层/留白/点苔」的**确定性映射表**，让「画什么、怎么画」不再散落在三首 pipeline 的硬编码里。
> **日期**：2026-10-03 ｜ **对应**：`model_cards.md` 卡片 2（意象）、卡片 5（构图）、卡片 6（笔墨）
> **定位**：D2 是图侧 L1 要素（三远/皴法/墨色/留白）的**共同上游**——一处改，三卡同步。

---

## 1. 为什么要有 D2

三首诗的 pipeline（`jiangxue_pipeline.html` / `baidicheng_pipeline.html` / `jingyesi_pipeline.html`）里，画法参数是**逐首硬编码**的：

```js
// 江雪
{ yuan: ["平远","深远"], cun: "无皴", ink: "清", blank: 0.79 }
// 白帝城
{ yuan: ["高远","深远"], cun: "大斧劈", ink: "重", blank: 0.52 }
```

换一首诗就要重推一遍，且三首之间**无法保证一致**（同一个「山」，在 A 里是披麻皴、在 B 里可能是斧劈皴）。D2 把这一步变成**查表 + 调制**：

| 环节 | 手工时代 | 有 D2 后 |
|---|---|---|
| 意象分类 | 人读 | `classify(word, head)` |
| 单节点画法束 | 人写 | `resolve_node(node)` |
| 三远/皴法/留白 | 逐首手算 | `resolve_poem(poem)` |
| 情感→墨阶 | 人估 | V/A/T 档 → `ink_steps` |

D2 属**桥接数据层**：输入是 O2 意象层（`o2_imagery.json`），输出是画法束，交给卡 5/6 求精确数值。

**分工铁律**：D2 只给「**候选集 + 类别档 + 区间约束**」；**精确数值**由卡 5 构图求解器与卡 6 笔墨物理给出。

## 3. 数据 schema（`d2_techniques.json`）

```jsonc
{
  "meta":   { "version":"1.0", "grade_scale":["原文","画史","通例","裁定"], "fields":{...} },
  "vocab":  { "yuan":{...}, "cun":{...}, "ink":{...}, "water":{...}, "stroke":{...},
              "layer":[...], "season":{...}, "format":{...} },
  "classes":       { "山石":{"keywords":[...]}, ... },          // 15 类
  "head_class":    { "山":"山石", "月":"天象", ... },            // 125 中心字
  "word_class":    { "孤舟":"舟桥", "两岸":"水体", ... },         // 81 词（含补遗 50）
  "class_defaults":{ "山石":{"yuan":[...],"cun":"披麻皴","ink_grade":"重", ...} }, // 15 束
  "word_override": { "两岸":{...}, "雪":{...}, "明月":{...} },     // 特例
  "modulators":    { "emotion":{V/A/T}, "layer_atten_steps":{...}, "layer_technique":{...},
                     "space":{...}, "season_words":{...}, "polarity":{...}, "form":{...},
                     "blank_rules":{...} },
  "rules":         [ {id:"R1", when:..., then:..., why:...}, ... ],  // 11 条
  "technique_triggers": { "diantai":{on,off,basis}, ... },
  "sources":       { "guoxi_sanyuan":{...}, ... }                // 16 条来源索引
}
```

**设计要点**

- **两级落类**：`word_class`（精确词）→ `head_class`（中心字）→ 末字兜底。词覆盖保准，中心字覆盖保泛化。
- **画法束 = 类别默认 → 调制器 → 词覆盖**：`class_defaults[类别]` 给基线，`modulators.layer_technique[类别][层]` 按景深细化（如 山石×远景 → 高含水/大晕染），`word_override[词]` 打补丁且**优先**（如「两岸」改判高远/斧劈、「万重山」保留层叠递淡）。
- **调制器而非硬编码**：情感（V/A/T）、景深衰减、景深笔法（`layer_technique`）、空间词、物候、极性各自独立，可单独调。
- **负节点/虚写/虚染**走 `role`：`不画`（负节点，约束留白）、`承载留白`（虚写，墨色记 `留白`）、`虚染`（虚写但**非**留白，以极淡墨湿渲成形，如彩云/霜）。三者都不参与情感墨阶位移。
- **词级角色优先**：`word_override.role` 优先于 gate 推导（`虚染` 覆盖「虚写→承载留白」）。
- **焦点保对比**（R4）：`role=焦点` 的节点**不随层衰减、不随情感位移**变淡（如「明月」虽在远景仍为淡阶），保证与背景拉开。

## 4. 怎么用

```python
from d2_resolve import classify, resolve_node, resolve_poem, load

t = load("d2_techniques.json")

classify(t, "两岸", "岸")                    # → ("水体", "word_class")
resolve_node(t, node, {"ink_steps": 1})      # 单意象 → 画法束
resolve_poem(t, "jx", imagery)               # 全诗 → 三远/皴法/留白区间/形制
```

```bash
python src/d2/d2_build.py            # 源+种子+补遗 → d2_techniques.json（含校验）
python src/d2/d2_resolve.py          # 三首回归 → d2_regression.json
python src/d2/d2_resolve.py --word 孤舟   # 查一个词的画法束
python src/d2/d2_compare.py          # D2 × pipeline 逐项对账 → d2_compare.json（接入前必跑）
python src/d2/d2_covcheck.py         # 覆盖率护栏 → d2_coverage.json
```

**诗级输出的关键字段**：`yuan`（三远候选）、`cun`（皴法）、`blank_range`（留白区间）、`solid_mass`/`mass_bonus`（实体质量项）、`motion`、`silence_ratio`、`season_qi`、`format_candidates`、逐节点 `nodes[]`。

## 5. 实测指标

### 5.1 回归校验（对照三首 pipeline 实跑值）——**20/20 全通过**

| 诗 | 三远 | 皴法 | 留白区间 ∋ 实测 ρ | 墨阶排序 | 虚写→留白 | 负节点不画 |
|---|---|---|---|---|---|---|
| 江雪 | 平远/深远 ✓ | 无皴 ✓ | [0.74,0.92] ∋ 0.79 ✓ | 孤舟>千山、蓑笠翁>千山、孤舟>独钓 ✓ | 雪、寒江 ✓ | 鸟、人踪 ✓ |
| 早发白帝城 | 高远/深远 ✓ | 大/小斧劈 ✓ | [0.38,0.58] ∋ 0.52 ✓ | 轻舟>两岸>彩云、轻舟>万重山 ✓ | — | — |
| 静夜思 | 不适用 ✓ | 不适用 ✓ | [0.76,0.92] ∋ 0.78 ✓ | 床>霜 ✓ | —（霜改判虚染） | — |

> **留白区间算法**（`blank_rules`，裁定·3 首标定）：
> `ρ = V档 blank_base + 负节点(+0.04) + 全域意象(+0.08) + 极简(+0.04) + 实体质量项`，再钳制到 `[0.30,0.92]`。
> **实体质量项（R11）**：`solid_mass = Σweight(role∈{主体,地标})`，低于参考值 2.0 的部分每 1.0 权重补 0.12 留白。
> 《江雪》mass=2.0（千山）、《白帝城》mass=7.0（白帝3+两岸2+万重山2）均不加成；《静夜思》mass=0 → +0.24，把「只有月光和一个背影」的极简夜景抬到 [0.72,0.92]。

### 5.2 覆盖率护栏——**词 88/88、实跑节点 22/22、中心字 11/15**

- 4 个中心字缺失（住/绝/里/钓）**均为可选**——其词已由 `word_class` 直接覆盖（不住/飞绝/千里/独钓），不构成缺口。

### 5.4 对账暴露的问题与修正

| # | 症状 | 根因 | 修正 |
|---|---|---|---|
| 1 | 彩云/霜被判 `留白`，与 pipeline 实写（c≈0.06/0.10）矛盾 | gate=虚写 无条件把 role 压成 `承载留白` | 新增 `虚染` 角色；**词级 `role` 优先于 gate**（`d2_resolve`） |
| 2 | 明月（焦点）在远景被层衰减压到 `清`，与 c=0.40 矛盾 | 焦点只豁免情感位移，未豁免层衰减 | R4 扩展：**焦点不随层衰减、不随情感位移** |
| 3 | 远山（千山）/万重山 含水=中、笔法=中锋·侧锋 | 山石类别默认按「近景山石」给，缺远山细化 | 词覆盖补 `water=高` + `stroke=大晕染·慢扩散`（千山）/`层叠淡墨·逐层递淡`+`cun=无皴`（万重山） |
| 4 | 白帝城/两岸/榻沿/月晕/霜 笔法名与 pipeline 不一致 | D2 笔法词表缺这些施笔名 | 词表补 7 条（点景·数笔即成 / 斧劈皴·侧锋快扫 / 层叠淡墨·逐层递淡 / 大晕染·几乎无形 / 染（湿渲）/ 染（上浓下淡）/ 写+染），建筑默认改「点景·数笔即成」 |
| 5 | 寒江/月晕/地上霜/榻沿 含水项误报偏差 | pipeline 对这些区**未标标准含水档**（特殊渲染/不画），脚本却按「应为极低」判 | 对账脚本：`water=None` 视为「未标档」，不计偏差 |

### 5.7 远山细化的泛化——调制器 `layer_technique`

§5.4 第 3 项把「远山（千山）高含水/大晕染」和「万重山」落在**词覆盖**（2 例）。本次按 §8 升级路径第 6 项，将其升级为调制器，使「**距离 → 含水/笔法**」可泛化：

```json
"modulators": {
  "layer_technique": {
    "山石": { "远景": { "water": "高", "stroke": "大晕染·慢扩散" } }
  }
}
```

**解析顺序**（`d2_resolve.resolve_node`）：`class_defaults[类别]` → `layer_technique[类别][层]` → `word_override[词]`。词覆盖**优先**——已被 `word_override` 显式指定的键不被调制器改写。

**词覆盖裁剪**

| 词 | 改前 | 改后 |
|---|---|---|
| 千山 | `water=高, stroke=大晕染·慢扩散` | **整条删除**（完全由 山石×远景 调制器给出） |
| 万重山 | `layer=远景, water=高, cun=无皴, stroke=层叠淡墨·逐层递淡` | 仅留 `cun=无皴, stroke=层叠淡墨·逐层递淡`（层叠特化）；`water=高` 由调制器给出 |

**验证（行为等价 + 泛化生效）**

- **行为保持**：回归 **20/20**、对账 **54/54**、覆盖率 **88/88 · 22/22** 全部不变；`src/d2/d2_inject.py --check` 三首快照**仍一致**——说明调制器对两例产出与改前**逐字段一致**，升级未改变任何已交付值。
- **泛化生效**：新词「远山」「孤峰」（`tail-char` 落类 山石、无词覆盖）在远景即得 `含水=高 / 大晕染·慢扩散`，无需逐词登记。
- **层范围限定**：仅 **远景** 生效；山石@近景/中景 仍为类别默认（中含水 / 中锋·侧锋），调制器按层限定、不泛化到全类。
- **构建期校验**：`src/d2/d2_build.py` 新增 `layer_technique` 的类别/层/含水/笔法/皴法合法性检查。

> **分工铁律不变**：调制器只给「档」（含水档、笔法名），精确数值（p、c）仍由卡 6 求解。
