中国古典音乐 · 表达要素研究报告

音乐能不能为「水墨 · 三首绝句」再添一层表达 —— 古典依据 · 可参数化要素 · 情感映射 · 与现有管线的接口

本报告回答一个问题：中国古典音乐有没有表达价值、能不能和画结合，如果能，它由哪些可参数化的维度构成、怎么挂到项目已有的「秤」（V/A/T、留白率、静默比）上、还缺什么。

结论先行：有价值，而且它是独立的一层，不是「配个背景音」。理由不是「好听」，而是三条可核验的古典依据——① 琴能造象（伯牙「志在太山 / 流水」）；② 诗画乐同源共用一个验收词「韵」（张舜民、苏轼、范温）；③ 声无哀乐（嵇康）——第三条同时是护栏：音乐本身不携带哀乐，所以只做「与画面同调」，不宣称音乐「直出」情感。真正可参数化的不是「风格标签」，而是调式（五声十二律）、音色、手法（吟猱绰注）、节奏（板眼）、结构（散起→入调→入慢→复起→尾声）、静默（大音希声）六个轴，它们能一一对上项目 D2 的 V/A/T 与 silence_ratio。主要缺口仍是既有的 D3（声法表 + 音源）。

依据：《吕氏春秋·本味》· 嵇康《声无哀乐论》· 徐上瀛《溪山琴况》·《黄帝内经·素问·阴阳应象大论》·《礼记·月令》· 王骥德《曲律》· 范温《潜溪诗眼》

§0

结论速览

① 有表达价值，是「独立的一层」

不是给画面配音。古典依据里，音乐自己就能造象（伯牙志在太山，听者见「巍巍乎若太山」），也能承担画面刻意留出的「虚」。

② 可参数化的是「六轴」，不是风格标签

调式 / 音色 / 手法 / 板式 / 结构 / 静默。每一轴都能下参数、能断言、能回改——像 layer_technique 一样进规则体系。

③ 直接复用现有「秤」

D2 的 V/A/T 与 T.silence_ratio 就是音乐参数的现成取值器；语音产出的「行时序_秒」就是音乐的时间轴。不需要新建时间体系。
一条必须先立的护栏：坊间流传的「宫音宽广、商音悲凉、羽音凄婉」这套逐音情感对应，查无可靠古典出处，属现代通俗说法（本项目《图声表达要素补遗》v3 已勘误）。古典能依据的是另一条链：五音 → 五行 → 五脏 → 五志（《素问·阴阳应象大论》）。本报告只用后者，前者一律标为「现代设计选择」。
一个结构性发现：琴曲结构与画面时间轴天然同构——「散起」＝空镜起兴（朱熹「兴」），「入调」＝主体，「入慢」＝余韵，「尾声」＝落款钤印。这意味着音乐不是贴在动画外面的轨道，而是可以与题诗逐句节拍共用一条时间线（§4）。
§1

为什么音乐能和画结合 —— 三条古典依据

先把「能不能结合」这件事的学理立住，再谈参数。三条依据分属「能力 / 同源 / 护栏」三种角色。

依据一琴能造象：伯牙「志在太山」

「伯牙鼓琴，钟子期听之。方鼓琴而志在太山，钟子期曰：『善哉乎鼓琴，巍巍乎若太山。』少选之间而志在流水，钟子期又曰：『善哉乎鼓琴，汤汤乎若流水。』」[7]
——《吕氏春秋·本味》。这是「音乐 × 山水画」最硬的古典依据：弹者以「志」造象，听者听出了山与水。它证明音乐可以携带（并被接收）视觉性的意象，而不只是情绪。

旁证：《溪山琴况》「速」况结尾同样收在伯牙——「天地自然的磅礴元气深深震撼了观者的内心，观者得之于心而应之于手，便也在指下奔涌出了天地间的万千气象」[2]。徐上瀛把「气象」直接放在指下，说明在琴学里「音」与「象」本是一事。

依据二诗画乐同源：共用一个验收词「韵」

来源原文对「音乐×画」的含义
宋·张舜民「诗是无形画，画是有形诗。」[8]诗、画本就互为表里；乐与诗同源（词牌原为曲调），故「乐—画」不必外求合法性
宋·苏轼「诗画本一律，天工与清新。」（本项目《图声补遗》已实证）确立「一律」——同一套审美标准
宋·范温《潜溪诗眼》「韵者，美之极」「有余意之谓韵」「大声已去，余音复来，悠扬宛转，声外之音」[9]「韵」是画与乐共享的验收词：画讲「气韵生动」，乐讲「余韵」——都是「有余意」
可操作的推论：既然「韵」的定义是「有余意」，那么音乐与画面的结合点就不是「同步」（同时发生），而是「余」——画面停住之后声音还在、声音落下之后画面还动。这直接对应项目已实现的「句间气口 / 余韵」，可升级为独立的余韵层。

依据三 · 护栏声无哀乐：音乐不携带哀乐

「和声无象」「声音自当以善恶为主，则无关于哀乐；哀乐自当以情感，则无系于声音」「音声有自然之和，而无系于人情」[1]
——嵇康《声无哀乐论》。嵇康的主张是：音乐只有「和」（形式之美），哀乐由听者的情感而生，不由声音自带。

这条对项目有两重意义：① 它是护栏——所以本项目不宣称「这段音乐会表达孤冷」，只说「让音乐与画面的 V/A/T 同调」；这与项目铁律「不直出」完全同构。② 它解释了为什么必须「同调」而非「贴标签」——既然哀乐由听者情感而生，那么当画面已经把情感铺垫好（V/A/T 已定），音乐只需要在形式层面（调式、音色、板式）与之对齐，听者自然会「因声而显」。

§2

可参数化的音乐要素（六轴）

把「中国古典音乐」拆成可下参数、可断言、可回改的维度——这样才能进规则体系，而不是一个笼统的「国风 BGM」。列「古典依据」是为了区分可核验与现代设计选择。

轴 A 展开五音配五志——古典能依据的那条链

《素问·阴阳应象大论》逐字给出了「五音 → 五行 → 五脏 → 五志」，并且额外给了「在声为……」这一列（声音形态），对做「乐 + 吟诵」尤其有用[3]：

五音五行 / 方位 / 时五脏五志（原文）在声为（原文）项目落点（设计取值）
角木 / 东 / 春肝怒呼未用（三首无怒）
徵火 / 南 / 夏心喜笑早发白帝城（V 正区 · 喜悦）
宫土 / 中 / 长夏脾思歌静夜思（V 中性偏负 · 思乡）
商金 / 西 / 秋肺忧哭未用（可备秋景诗）
羽水 / 北 / 冬肾恐呻江雪（V2 孤冷 · 冬雪寒江）
为什么这条链可用而「宫=宽广」不可用：前者是古籍原文的对应表（可核验、可挂源）；后者是把「听觉印象」直接说成「情感」，查无古典出处。现代音乐学另有一套<「调式色彩」分析（如阿炳作品研究中「徵类色彩＝宽广温暖」「羽类色彩＝柔美暗淡寒冷」[17]），但它属现代分析，本项目只用它作旁证、不作判据。
律历对应可直接复用：《礼记·月令》把十二律与十二月绑定（孟春「其音角，律中大蔟」……仲冬「律中黄钟」[4]）。这与项目已采纳的郭熙「四时山景」（春山如笑…冬山如睡）是两套可并行的「季节轴」——一套给画，一套给乐，同源于「时」。

轴 C 展开吟猱绰注——「余韵」的物理来源

四种左手走手音

吟：按指小幅快颤（幅度小、速度高）→ 音色温润
猱：按指大幅慢颤（幅度大、速度低）→ 起伏明显
绰：上滑音（由低滑向本位）
注：下滑音（由高滑向本位）
出处：华音网《中国传统音乐分析（古琴篇）》、国琴网「吟猱绰注」专题[11]

为什么它对本项目关键

古琴的「韵」不在音头，而在音之后的走手音——这与水墨的「墨在笔之后渗化」是同一种时间结构。项目的笔法已用 t^0.5 物理式表达渗化；音乐侧的对应物就是绰注 + 吟猱的余音衰减。两者可共用一个「余韵时长」参数。

§4

与项目现有管线的接口

音乐层不需要另起一套时间与情感体系——项目已有的三件东西正好就是它的「插座」。

已有能力现用途音乐层的接法
voice_prosody_process.py 的「行时序_秒」 动画按配音实测行时序重排，保证声画严格同步 音乐挂在同一条时间轴：四句诗＝四个乐句；末句韵脚落印处＝尾声（可让终止音与钤印同帧）
D2 T.silence_ratio（T1 0.1 → T5 0.32） 画面留白 / 静默预算 直接当音乐的静默比：白帝城 0.10 → 几乎不断；江雪 0.32 → 初版照搬为「乐句之间留白」，实施后听感为「断」，改取连贯（见 §6）
D2 V/A/T 分档 画面墨色、留白率、运动 查 §3 表取调式 / 板式 / 配器，与画面同档 → 同调
句间气口（170ms 吸气噪声）+ 句间渐弱 语音衔接 升级为独立「余韵层」：气口处不加音乐（或让音乐单独现出），实现「画停声在 / 声落画动」

混音人声为前景，音乐走闪避（ducking）

侧链压缩（sidechain / ducking）：以人声为触发源，人声出现时自动把音乐压低 6–10 dB（音乐目标约 −18 ～ −24 LUFS），人声间隙恢复。这样既保住「音乐在场」，又不与吟诵抢清晰度。
两个工程约束（与项目既有教训一致）：① 声画同步的「尺子」必须与音频总时长一致——音乐轨时长须等于配音实测总时长（含句间停顿），否则重演「尺子与画脱节」的静默漂移。② 带声动画会被浏览器自动播放策略拦截，须沿用项目既有做法：先静音播画面，用户手势（点「播放/重播」）后带声。
资产位置：现有 dist/audio/voice/ 只有语音，没有任何音乐资产。音乐需新增目录（建议 dist/audio/music/），并按诗命名（jx.mp3 / bd.mp3 / jys.mp3）。

现代可落地手段（已核查）

手段可核验事实对本项目的适配度

通用文生音乐（如 MuseLM / 灵音） 腾讯音乐发布「文生音乐」能力[13] 低 多给「风格标签」，不给调式/板式，难与 V/A/T 精确对齐
三条风险（须先解决再落地）：① 版权——名家演奏录音、商业音源库（如各类古琴采样）不可直接商用；「老八张」等历史录音亦然。须走可商用音源库或 AI 生成（并确认生成物的授权条款）。② 可控性——多数文生音乐只接受「国风 / 古琴 / 舒缓」这类标签，不给调式与板式；若要用 §3 的映射，须选支持 MIDI / 符号控制或分轨导出的方案。③ 同步——生成音频若无法拿到 stems 或精确时长，就无法与「行时序_秒」严格对齐。
§6

数据缺口与实施顺序

承接《图声要素的数据可得性与模型映射》里的 D3（意象—声法映射表 + 音源库）。本文 §3 的映射表就是 D3-1 的初版。

· 护栏：--check 断言时长 / 最长静默 ≤ 0.30s（连续性，100ms 窗、−40 dBFS 门限）/ 峰值 / 波峰因数 + 「处方兑现」（音高落点、走手音真滑）+ 「音色护栏」（与参考采样的频谱包络距离 ≤ 3.0 dB）； --selftest 以负向扰动证明断言可失败（非空断言）。已纳入 build/verify.py 与交付包装配。
· 一处工程记录：亮按音的二倍频常与基频等强，故音高校验不能用 FFT 峰值（会误判 2f₀），须用自相关取基频周期——这是「护栏要可信」而非「模型要好看」的一例。
· 一处听感修正 → 音源替换（2026-10-05）：初版合成拨弦被听出「电子滴答」。先按「音头是 <0.5 ms 宽带『咔』」修补（激励改环形一阶低通、环路阻尼 0.55→0.72、去 12 ms 白噪爆点、加 5 ms 升余弦软起音），音头上升 0.32–0.48 ms → 2.7–3.0 ms，但听感仍未根除。 遂改采样替换：古琴音源整体换为真实录音干声，宽带瞬态在源头即不存在。护栏口径随之从「音头上升时间」升级为「与参考采样的频谱包络距离」（零变调渲染后 24 带对数包络 RMS ≤ 3.0 dB；实测 0.08–0.16 dB，白噪「滴答」23.5 dB 被判失败）。诊断与盲听材料存于 _archive/_scratch_diag_2026-10-05/。
· 一处听感修正 → 全曲连贯（2026-10-05）：初版把配音的行间气口照搬为音乐静默（静默占 31.7%、最长 1.76s），默认「纯音乐」模式下听感为「断」，且入声「顿」把音长截到 0.5s 另生行内空隙。改为每个音「响到下一次起音 + overlap」（rules.ring_max_s / note_overlap_s），气口由前音余响 + 低散音（breath_events）贯入；实测静默 31.7% → 1.1%（仅曲末 300ms 自然收尾），最长 1.76s → 0.22s。护栏由「静默比 / 静默段 RMS」改为「最长静默 ≤ 0.30s」，并以负向扰动（抹掉一段 → 判失败）证明非空断言。
