摘要

两条路的诊断结论

结论与上一阶段的直觉相反：「找一段现成的真人吟诵来用」几乎走不通，但「自己按规则吟出来 / 用工具改出吟诵味」是可行的。

现成真人吟诵
● 不可直接用

国内两大吟诵音像库（中华吟诵学会田野档案、叶嘉莹教学录音）均非开放授权：一个以加密 U 盘商业出版，一个版权归属存在司法纠纷。开放语料里唯一的音频库 MCGA 是朗读而非吟诵。

自录真人吟诵
● 可行

吟诵规则已被系统化为「一本九法」，可写成确定性参数谱；不依赖天赋，按「平长仄短、入短韵长」即可产出有韵味的样本。门槛在录音环境与时间成本。

韵律后处理
● 技术可行，需自研

Praat/parselmouth 的 PSOLA 与 pyworld 的 WORLD 声码器都能改写 F0 与时长。学界已有面向汉语声调的「声调叠加」标准流程。风险是声调失真与机械伪影。

关键判断

没有「开箱即用的真人吟诵音频」可合法取用。中华吟诵学会的采录档案以「加密 U 盘 + 图录」形式商业出版，叶嘉莹的教学录音版权存在司法争议——两者都需授权，不能直接嵌入作品。[cite:1][cite:2][cite:3]

路径建议

把「韵味」拆成可控的两件事：音高轮廓与时长结构。音高靠「依字行腔」（保留每个字本来的声调，不破坏），时长靠「平长仄短、入短韵长」（这是吟诵最可辨识的特征，也最容易用后处理实现）。据此，先做自录样音 + 后处理两条并行的最小验证，用听测裁决。

01

真人吟诵音像资源与版权审计

逐个来源核对「有没有、能不能合法用、是吟诵还是朗读」三件事。

  • 第四十二条：录音制作者使用他人作品制作录音制品，应取得许可并付酬；使用已合法录制的音乐作品制作录音制品，可不经许可但须付酬，权利人声明不许使用的不得使用。
  • 第四十三条：制作录音录像制品，应与表演者订立合同并付酬。

落到本项目：「诗」本身已过版权期（公有领域），但「某人的吟诵录音」是独立的表演 + 录音制品权利。因此不能因为诗是公版的就随意使用吟诵音频。CONFIRMED

可行的合规来源：自录

既然现成音频不可取，自录就是唯一完全可控、无版权风险的真人吟诵来源。可行性依据：

  • 规则明确可学。吟诵规则已系统化为「一本九法」：依字行腔、依义行调、入短韵长、平长仄短、平低仄高、文读语音、腔音唱法、模进对称、虚实重长。[cite:5][cite:6]
  • 规则可直接转成参数。例如「平长仄短」的判据是：偶位字（二、四、六）为平声则读长音，句尾韵字读长音，入声字一律读短音，其余读中音——这是可编码的确定性规则。[cite:7]
  • 教学资源公开。吟诵教学已进入 500+ 所中小学，MOOC、公开课与「吟诵堂」类材料可自学入门。[cite:8]

门槛：需要一段安静环境与一两个小时的试录；音准与气息可后期修。风险最低、确定性最高，且产物可版本化（与项目「可度量」原则一致）。

小结

「现成真人吟诵」这条路应放弃——不是找不到，而是找到的都不能合法用。真人吟诵只能走自录；如果连自录也不做，就只剩TTS + 韵律后处理这一条技术路。

02

把吟诵规则写成可执行韵律谱

这是后处理链路的「谱」——后处理需要一个明确的目标曲线，而吟诵规则恰好提供了它。

「一本九法」中与韵律直接相关的六条

法则含义可转成的参数
平长仄短平声字长、仄声字短每字时长 duration
入短韵长入声字最短、韵脚字最长入声 = 最短档；韵脚 = 最长档（拖腔）
平低仄高平声字音低、仄声字音高每字音区 register
依字行腔按字本来的声调走向行腔每字 F0 轮廓形状（不可破坏声调）
依义行调按句义决定整句音调走向句级 F0 基线 + 情感弧
模进对称相邻句用相似旋律型、对称呼应句间 F0 轮廓的复用/镜像

「文读语音」「腔音唱法」「虚实重长」属于发音与演唱技法，后处理阶段不纳入（前者需人工文读，后两者属演唱层）。[cite:5][cite:6][cite:7]

此谱是设计性构造，不是「《静夜思》的唯一正确吟法」——传统吟诵存在流派与方言差异，同一首诗可有多套腔调。本谱的作用是给后处理一个可复现的目标，与项目「可度量」原则一致。设计选择，非唯一解

03

韵律后处理技术链路

目标：输入一段「平读」音频，输出带「平长仄短 + 依字行腔」的目标音频。

工具对比

工具原理能做什么风险本项目
Praat（PSOLA） 基音同步叠加，逐基音周期改写 F0 与时长 F0 曲线任意重绘、时长拉伸/压缩；内置 Stylize pitch 可简化轮廓 过度改写会产生机械感；声调可能被改坏 首选（有标准流程）
parselmouth Praat 的 Python 封装 脚本化调用 Praat：Manipulation → Get resynthesis (overlap-add) 同 Praat；API 需熟悉 自动化首选
pyworld（WORLD） 分解为 F0 / 谱包络 sp / 非周期 ap，再合成 音高缩放、变速、共振峰保持；harvest+stonemask 提 F0 共振峰与音高耦合，大改易出伪影 备选（先分解再定制）
librosa / soundfile / ffmpeg I/O、重采样、格式转换、简易变速变调 读写、切分、拼接、批量处理 变速变调会同时改变音色 必备配套

WORLD 把语音参数化为 F0 轮廓、谐波谱包络、非周期谱包络三部分并可再合成，是「先拆解再按谱重绘」的路线。[cite:9] Praat 的 PSOLA 可在每个基音脉冲处指定 F0，是「直接重绘」的路线。[cite:10][cite:11]

学界已有的汉语声调处理流程：「声调叠加」

Frontiers in Education (2024) 的教程系统给出了一套可复现流程：把某个汉语声调的音高轮廓叠加到另一段音节上，并保持自然度。[cite:10] 其要点与对本项目的启示：

步骤做法对《静夜思》的意义
1. 提取 F0对源音节做基频分析得到「平读」音频每个字的原始音高
2. 简化轮廓Stylize pitch (2 ST)，剔除小于 2 半音的小波动去掉朗读的自然抖动，得到干净的字调骨架
3. 设定目标轮廓按目标声调/腔型，在 Manipulation 上逐点设定 F0注入「依字行腔 + 平低仄高」
4. 再合成Get resynthesis (overlap-add)（PSOLA）输出改写后的音频
「Manipulating the pitch contour in a spoken syllable can be complicated and change the perception of the spoken syllable in a significant way.」 — 该教程摘要（原话：改动音高轮廓可能显著改变音节的听感）[cite:10]

最大风险：声调保全（依字行腔的反面）

汉语是声调语言，音高既负载声调（字义）又负载语调（情感/句调）。这与英语不同——英语里音高只表情感，随便改不会改字义。[cite:10]

  • 红线：不能把「明（阳平，升↗）」改成降调，否则听成别的字。
  • 安全区：改时长（平长仄短）几乎不损伤声调辨识；改整体音区（平低仄高，即整体平移）也相对安全。
  • 危险区：逐点重绘 F0 形状——必须在「保留本字声调走向」的约束下做，只能强化/微调，不能反转。

因此后处理应优先动时长、次动音区、慎动形状。这也解释了为什么「平长仄短」应作为吟诵韵味的主抓手——它最有效且最安全。

已知限制

  • PSOLA 与 WORLD 都不擅长大幅、长时的 F0 重绘（如整句拖腔），拖腔越长越易出颤音/金属感伪影。
  • 没有检索到「用 PSOLA 给五言诗逐字注入平仄」的现成开源工具或脚本——需自研，属研究性投入。工具缺口
  • 「腔音唱法」（吟诵特有的腔化演唱）无法用后处理还原——那是演唱技法，只能靠真人。
04

《静夜思》韵律后处理 pipeline 设计

两条并行输入（自录音 / TTS），汇入同一条按谱重绘的链路，最后人工听测裁决。

1

取源音（两路并行）

路 A · 自录：按九法慢读《静夜思》，一句一录（便于逐句对齐），保留较长停顿。
路 B · TTS：用男声（Yunyi poet / Yunhan lonely+whispering）逐句生成，作为后处理底料。

2

切分与对齐

用 librosa / soundfile 读入，按静音段切出 20 个字的边界（自录）或按 TTS 时间戳对齐（TTS）。输出「字 → 时间区间」表。

3

F0 分析 + 轮廓简化

parselmouth 建 Manipulation；对每字用 Stylize pitch (2 ST) 去抖，得到干净的字调骨架。

4

按谱重绘（核心）

读入 §2 的韵律谱：
· 时长：平声 ×1.6、韵脚 ×2.2（拖腔）、入声 ×0.55、上去声 ×0.8（安全区操作）；
· 音区：平声整体 −2 半音、仄声 +1 半音（平低仄高，平移操作）；
· 形状：保留本字声调走向，仅对韵脚做末端轻微下行的拖腔延长（危险区，最保守）。

5

再合成与拼接

Get resynthesis (overlap-add) 输出逐字音频；按「起承转合」的停顿预算（0.3 / 0.6 / 0.4 / 0.8s 前停 + 句尾 1.0 / 1.5 / 1.3 / 2.0s）拼接成整首。

6

听测裁决（可度量）

同一段文本产出 4–6 个版本（自录原声 / 自录+后处理 / TTS / TTS+后处理），做小样本盲听，维度：声调可辨、时长对比是否自然、有无伪影、情感是否到位。用结果决定是否值得继续投入。

06

结论与建议

三条结论

  • 真人吟诵：现成音频不可合法取用（吟诵学会加密出版、叶嘉莹版权缠结、MCGA 是朗读）。唯一合规的真人来源是自录，且规则明确、可自学。
  • 韵律后处理：技术可行（Praat PSOLA / pyworld WORLD），学界已有汉语「声调叠加」标准流程；但无现成开源工具给五言诗注入平仄，需自研。
  • 抓手的优先级：时长（平长仄短）＞音区（平低仄高）＞形状（依字行腔）。前两者安全且有效，后者是「韵味」的核心但也最容易翻车。

建议的下一步（最小验证，成本递增）

第 1 步

自录一版《静夜思》样音

按九法慢读，一句一录。先不做任何后处理，直接听——判断「真人吟诵」这条路是否值得走下去。

成本：约 1 小时。收益：立刻获得一个无版权风险、带真实韵味的基准。

第 2 步

搭一个「只动时长」的后处理最小脚本

用 parselmouth / librosa 实现「平长仄短 + 入短韵长」的时长改写（不碰音高）。这是最安全的一档，能验证「时长是否就是韵味的主要来源」。

成本：半天。收益：可度量、可回归的时长谱，直接进项目评估链。

第 3 步

（条件触发）加入音区与拖腔

仅当第 2 步听测显示「时长不够、还差味道」时，才动音区与韵脚拖腔——进入危险区，需逐字核验声调未失真。

风险：伪影与声调失真，收益递减。

一句话

先用一小时的真人自录证伪或证实「韵味可及」，再决定是否投入后处理工具链。不要把研究性投入压在还没验证的需求上——这与项目「先可度量、再可规模」的顺序一致。
