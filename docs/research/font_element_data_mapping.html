字体要素 · 数据来源映射

诗 ↔ 数据源提取 → 字体 9 维定档

上一份报告（字体 · 表达要素研究报告）把字体拆成 9 个可参数化维度，并指出它是唯一同时横跨「构图 / 笔法 / 时间」三层的要素。本文件回答下一步：这 9 维的取值从哪来——不是拍脑袋挑字体，而是从 pipeline 已有的产物里推出来，像 layer_technique 那样进规则体系。

结论：数据侧零缺口。D1 格律、D2 画法、D6 情感、D5 语境、O2 意象已经把 9 维所需的输入全部产出；缺的只是一张把它们接到字体上的规则卡。

§2

表达角度：书体谱系 ↔ 情感空间（草档补什么）

书体的「收 / 放」本身就是情感维度——它直接对应唤醒度 A：篆隶极收（古拙）→ 楷收（端严）→ 行半放（洒脱）→ 草放（狂放）；同一书体内再以「圆厚 / 瘦劲」分冷暖（效价 V）。于是字体谱系可当成 A–V 平面上的一组档位，与 emotion_lexicon.taxonomy 的 14 类情感逐一对照，看哪档接得住哪类诗情。

书体档收放（↔ A）冷暖（↔ V）字体接住的情感
篆极收—敬峰中山王篆（仅印章）印章专用，不作题诗
隶极收（A 极低）古拙阿里妈妈刀隶体谱系占位，三首未用
楷 · 温润收（A 低）中性偏暖霞鹜文楷闲 / 爱
楷 · 开张收（A 中低）暖（V+）马善政毛笔楷喜 / 爱
行楷 · 瘦劲半放（A 低中）冷（V−）龙藏寂 / 愁 / 哀 / 思
行 · 流动半放（A 中）中性志莽行书忧 / 欲 / 恶 / 怨
草 · 狂放放（A 高）中性偏冷柳建毛草 新落地怒 / 惧 / 惊

草档补的是「高唤醒空档」：加草档前，A ≥ 0.70 的 怒（0.85）/ 惧（0.70）/ 惊（0.85） 三档无字可接（14 类里 3 类落空，且都集中在 V− 高唤醒区）；加草档后 14/14 全接住。至此书体谱系 篆隶楷行草 齐备，A–V 平面四象限均有档位。
还要不要更多字体？——不必，除非换赛道。谱系补齐后，剩下的候选各有明确阻碍：瘦金体（峭拔清瘦，本可接「孤冷 / 清峻」）无 OFL 开源源（王汉宗系为 GPL，不可自持子集）；篆 / 隶用于正文辨识度低、不合题诗惯例；再拆一款草（小草 / 大草）属过细，A 轴上已无空档。故结论：字体数到此为止，后续投入应转向「题款卡」（把 14 类情感 ↔ 书体档的映射固化成规则），而非再加字库。

§5

接线点与现状

层落点现状
数据侧D1 格律 / D2 画法 / D6 情感 / D5 语境 / O2 意象零缺口 9 维所需字段全部已产出，无需新数据源。
规则侧新建「题款卡」规则文件（形如 data/source/d2_seed/*.json），含 §3 的映射与 §4 的 gold缺 目前字体无规则卡，取值散落在 ink_animations.html 的 cfg.poem 里手工填。
渲染侧cfg.poem 增 face / inkGrade / tracking / sealStyle；build/font_subset.py 支持多字族子集；书写动画转 path 字形 + 逐笔遮罩部分 face / authorFace 已接线（江雪→龙藏、白帝城/静夜思→马善政、落款→志莽）；font_subset.py 已扩为七款字族表（含草档柳建毛草），并把印章篆体内嵌进全链路页；书写动画已升级为真笔顺（build/stroke_data.py → dist/animation/strokes.js，题诗/落款逐笔运笔，数据缺失时降级为矩形揭示）；inkGrade / tracking / sealStyle 未接线。
校验侧build/verify.py 增：字体覆盖 + 笔锋带覆盖 + 墨色档断言 + 书体档与 V/A/T 档一致部分 font_subset.py --check 管「子集覆盖 + 动画引用 + 全链路页内嵌印章篆体」；stroke_data.py --check 管「strokes.js 与字体/源同步 + 笔锋带覆盖外凸 ≤ 0（末笔走完即字形本体，无空洞/不串笔）」，均已纳入 build/verify.py；「取值是否符合规则」（书体档 ↔ V/A/T、墨色档）仍未断言。
书写动画已收口：原先「逐字写出」是 clipPath 矩形揭示而非真笔顺——毛笔字被一块矩形自上而下揭开，容易看出是「假书写」。现已升级为 path 字形 + 逐笔中线遮罩：每字取字形轮廓作 <path>，被 mask 遮住，mask 内按笔顺铺「笔锋带」并以 stroke-dashoffset 逐笔展开。笔顺与中线取自 hanzi-writer-data（Make Me a Hanzi，Arphic Public License），字形取自持字体子集，二者在 build/stroke_data.py 合并（中线换算到 upem=1000 并按 RDP 简化，逐笔遮罩带宽由轮廓边界点归属最近中线算出）。
