0.2 三条入选判据（沿用补遗，不放松）

① 可参数化

能落到「量」——位置、比例、档位、时长、密度。只有形容词的，不收。

② 可核验

有出处（书 / 作者 / 朝代），引文回到原文。二手解读只作旁证。

③ 不直出

不能把抽象情绪画成图解或贴标签。要素只走判据通道与结构通道。

0.3 可度量性四档（本文的核心标尺）

档含义典型要素确定手段
M0 可数离散枚举，取值即一个词形制、皴法、墨阶、含水档、四时、三远词表（查表即得）
M1 可测连续量，有量纲留白率 ρ、视觉重心 g、地平线位置、层数、人高占比、有效墨浓度 eff、柔度 σ、山:树:人比例、明度三面；品格 12 算子（S / F / H / Δ / R / Y / P / Sym / C 等）度量 / 约束求解
M2 可判需判据 + 判读，非数值直接可得；其中品格归属已可拆为 12 算子、落到二维平面判档（M1 支撑）品格归属（逸神妙能）、有我 / 无我、雅俗、势之优劣算子判档（见 专文）；LLM / 人工量表退居效度校准
M3 不可直出只可作约束或验收，不可作生成参数气韵生动（聚合涌现量）、传移模写（过程）作验收指标（O1）
0.4 一句话结论（全篇的支点）。山水画要素里，真正「不可度量」的极少——气韵是唯一的 M3。而气韵之所以不可直出，古人早已说破：龚贤「三者得而气韵生矣」——气韵不是独立可调的旋钮，是笔法 / 墨气 / 丘壑三者的涌现结果。故它在项目里的正确位置是 O1 验收指标（护栏），不是 D2 的生成参数。这与项目既有定位「O1 是护栏而非目标」完全同源。
更硬的依据来自郭若虚《图画见闻志·论气韵非师》：「六法精论，万古不移。然而骨法用笔以下，五者可学。如其气韵，必在生知，固不可以巧密得，复不可以岁月到」——古人早已把气韵判为不可学、不可岁月到，即不可作参数训练。这是 M3 结论最直接的古证。

三远 「山有三远：自山下而仰山颠，谓之高远；自山前而窥山后，谓之深远；自近山而望远山，谓之平远。高远之色清明，深远之色重晦，平远之色有明有晦。高远之势突兀，深远之意重叠，平远之意冲融而缥缥缈缈。」（郭熙《林泉高致·山水训》） 由「视点高度 + 层数 + 色明晦」共同判定：高远=仰视、少层、清明；深远=穿透、多层、重晦；平远=平视、横展、有明晦。 M0 已覆盖
三远（韩拙补） 「郭氏谓山有三远，愚又论三远者：有近岸广水，旷阔遥山者，谓之阔远；有烟雾溟漠，野水隔而仿佛不见者，谓之迷远；景物至绝，而微茫缥缈者，谓之幽远。」（韩拙《山水纯全集·论山》） 阔远=水占比大；迷远=雾高对比低；幽远=减笔 + 极低对比。合郭熙成「六远」。 M0 已覆盖

以大观小
折高折远		 「大都山水之法，盖以大观小，如人观假山耳；若同真山之法，以下望上，只合见一重山，岂可重重悉见？……李君盖不知以大观小之法，其间折高折远自有妙理。」（沈括《梦溪笔谈》卷十七·书画） 散点透视的理论总纲：画家视点不钉在地面，而「如观假山」——居高俯瞰且可移动，故能「重重悉见」。它解释了「三远」为何能并存，也解释了为何不能用单点透视去校验中国山水——它是「山形步步移」的上位原理。已用作 viewpoint「俯视」档的古典依据（补三远未覆盖的俯视，G7）。 M2 已覆盖
龙脉
（气势的结构化）		 「画中龙脉，开合起伏……龙脉为画中气势源头，有斜有正，有浑有碎，有断有续，有隐有现，谓之体也。开合从高至下，宾主历然……起伏由近及远，向背分明……谓之用也。……故强扭龙脉则生病，开合逼塞浅露则生病，起伏呆重漏缺则生病。」（王原祁《雨窗漫笔》） 把「气势」拆成可判项：龙脉（体）＋ 开合（用）＋ 起伏（用）。并给出三种病态（强扭 ／ 逼塞浅露 ／ 呆重漏缺）作负判据。这是「势」这一 M2 项唯一被古人写成结构清单的文本。 M1 缺口

① 「远望取势 / 近看取质」给了相机运动古典依据——项目相机 s(t) 由远到近时，诉求应从「势」切到「质」。据此，度量断言分视点设阈：远景帧只验构图与气势（层数 / 留白 / 重心），近景帧才验笔墨质感（eff / σ）。已落地为 viewpoint 视点档（平 / 俯 / 仰），根治此前「相机推拉导致人物 size 漂移」的口径之争——静帧基准取「势」档，运动帧不追绝对量。
② 「烟霞锁腰」是造高远的遮挡算子，不是尺度算子。项目已有云层（bd-cloud），可把「云锁山腰」参数化为「遮挡带位置 + 遮挡率」，补进 layer_technique 的同类机制。

3.2 三个边界问题

边界一：M2 的「可判」不是「不可度量」。品格、势、雅俗确实不能直接读数，但它们可以被拆成可数的判据。例：逸格「笔简形具」→ S 简度低 ＋ F 形具度高；南北宗 → R 刚柔比 高 / 低。轴1 已把它推进为「12 算子 + 二维平面（简繁 × 形具）+ 三带分区」——三带互斥无空隙（v1.1 修，11 组样例 ＋ 全域 2601 点扫描通过）。《江雪》无斧劈 + 极简 → 逸格 + 南宗，是可算的，不必靠感觉。详见 专文。
边界二：M1 的连续量必须绑定「视点」。郭熙「远望取势、近看取质」意味着同一个量（如人高占比）在远 / 近视点下诉求不同。故 M1 量分两类：相对量（ρ、g、层数——不受相机缩放影响，全帧成立）与绝对量（人高占比、eff 的绝对值——随相机 s(t) 漂移，只应在静帧基准判定）。此前「相机推拉致人物 size 越档」之争，正因未区分二者。
边界三：M3 只有一个——气韵。把气韵建模为可调参数，等于把「涌现量」当旋钮，必然导致图解化。正确做法：气韵 = 其余七轴的一致性函数，由 O1 验收。这与项目「O1 是护栏而非目标」的既有定位同源，也与龚贤「三者得而气韵生矣」同源。

3.3 关键洞察（三条）

① 气韵是聚合量

不是参数，是验收。→ 不要新建「气韵模型」。

② 势 / 质随视点切换

远验势（构图）、近验质（笔墨）。→ 断言分视点设阈。

③ 遮挡即造远

高远靠云锁腰，不靠放大。→ 尺度不是唯一手段。

轴1 的深挖。本章把 M2 的「可判」拆成可数判据，只给了示例（逸格 → S 简度低 ＋ F 形具度高）。轴1「立意与品格」的完整度量方法另见专文：《立意与品格的可度量方法》——把品格推进为「简繁 × 形具」二维平面上的坐标（逸格＝左上角，需两约束同时成立，故「最难其俦」），配 12 个可从冻结场景矢量基元直接算得的算子、立意三率、以及「先算得出 → 再校得准 → 后判得稳」的效度路径。
关键结论：品格可测、气韵不可测，且分界有古证——郭若虚「骨法用笔以下五者可学，气韵必在生知」。可学者可度量，生知者不可度量；轴1 因此天然分两半：品格落在可测区，气韵（轴0）留在 M3。本报告不改变 §0.4 的 M3 结论。

3.4 生成可控性：与「可度量」正交的另一维（摘要）

M0–M3 回答的是「能不能读数」，却不回答「能不能拧」。同一个 M1 里，既有可设的旋钮，也有只能读的仪表。把两者分开，才知道哪些要素真能当生成参数、哪些只能作验收。本节只留结论；控制链五段与 L1–L4 分层已独立成篇，详见 《生成控制整体架构》（该文为控制链与 L1–L4 分层的唯一真源，四层定义与八轴旋钮清单均在其中）。

两条结论（全文结论，细节见专文）。① 真正「直接可控」的是轴2–轴8 的 M0 枚举与 M1 输入量——它们都有现成旋钮（class_defaults · word_override · vocab），改一个键就变；轴0 气韵、M1 的输出量（eff / σ / 实测人高占比）与 12 算子不可控，也不该可控，只作验收（L4）。② 轴1 品格是「闭环反控」而非直出——12 算子先读出当前落档，style_grade 再反推该调哪些轴档位。故 §3.2 边界二区分「相对量 / 绝对量」，本节再区分「输入量 / 输出量」：前者是旋钮，后者是仪表。

8.4 仍未收 / 存疑（诚实登记）

三条存疑（已在 §6 标注）：①顾恺之「迁想妙得 / 以形写神」两条为后世转引，原文可靠性中等；②齐白石「似与不似」为语录、非署名字句；③黄公望「邪甜俗赖」四字确文可核、但释义属后世。三者皆「据义可引、据字须慎」——正文引用时已降级标注，不进入需精确原文的断言。
一条未收：「六法」的气韵 / 骨法 / 应物 / 赋彩 / 位置五法已分属各轴，唯「传移模写」为过程项（已补为轴0 条目）；六法本身不另立轴——它是「评价体系」，与八轴这套「生成要素」是两个坐标系（见 §1）。
