04

设计依据

声学映射（研究报告 · CONFIRMED）

思乡属低唤醒情绪：低基频（pitch ↓）、慢语速（rate ↓）、长停顿（pause ↑）、弱强度（volume ↓）。四句按「起—承—转—合」做一条极缓的抑扬弧：承句最低（疑），转句微扬（举头），合句跌回最低（低头怅惘）。

转句音高回到 1.0、合句降到 0.8——整体仍压在「低」区间，不做大起伏，守住「静夜」基调。

吟诵传统的参数化近似

用「前导停顿 + 尾静默」近似吟诵的句末拖腔与2+3 节奏：句末字读完后留 1.0–2.0s 的余韵，比逐字均匀更接近「平长仄短」的听感。

这是近似而非真吟诵——Web Speech API 无拖腔/入声能力，原型验证「朗诵 + 严格静默」的可行性；若意境增益不足，再对照真人吟诵采样评估（路线 C）。

静默预算协同

动画视觉静默段（5.0–6.0 / 9.5–11.0 / 14.2–15.5 / 20.0–22.0）全部无声；人声只在起/承/转/合的动作段出现。句间停顿自然落在句尾，不与画面运动冲突。

「留白当空间、不当噪声」——本原型默认人声结束后至少保留 1.0s 无声，可由尾静默参数控制。

可度量 · 可回归

四句 ×（rate/pitch/volume/pre/post）共 20 个参数全部显式记录，与动画时间轴一一对应。若纳入 O1 评估链，可加判读项：「配音参数与情绪设计是否一致」「人声是否侵入静默段」。

当前语音质量依赖系统安装的中文语音包；如需稳定质量，后续可平移至 Azure SSML（同样参数体系，支持更细的 break/emphasis）。
