§1

底座全图：五层

数据自下而上流过五层：原料层是外部输入，抽取层把诗变成结构化节点，桥接层把意象 / 情感映射成技法与声法，规则层是画论整理成的词表与调制器，消费层是求解器与落地（非数据，列作去向）。

为什么把「桥接层」单列。因为它是本项目最关键的一层：诗里没有「皴法 / 三远 / 留白率」，这些全是「意象 × 映射」的结果。底座 2 建好了，底座 3 才有取值空间；底座 2 只建了一半（画法有了、声法没有），是当前最不对称的地方。

  • G9 品格 12 算子（依赖 G2 + G10）
  • D4 情感—韵味锚定集（依赖 Wave 1 度量闭环）
  • D3 声法表 + 音源库（依赖 D2 范式；0→1，最重）
为什么 D3 / D4 排到最后。它们不是不重要，而是被别的波卡住：D4 是「天花板」（韵味 / 情感），要先有 Wave 1 的度量闭环才谈得上调；D3 是从 0 到 1 的音频资产建设，要先有 D2 桥接表的「意象 → 要素」范式可仿。先做它们，只会返工。
