现有卡片已覆盖：意象（卡2）、构图（卡5）、笔墨（卡6）。**以下是缺口。**

### 1.1 空间法：三远 ➕六远——构图卡缺的「纵深轴」
郭熙《林泉高致·山水训》原文：
> 「山有三远：自山下而仰山颠，谓之高远；自山前而窥山后，谓之深远；自近山而望远山，谓之平远。**高远之色清明，深远之色重晦，平远之色有明有晦。** 高远之势突兀，深远之意重叠，平远之意冲融而缥缥缈缈。」

| 远 | 影响什么 | 参数化建议 |
|---|---|---|
| **高远**（色清明、势突兀） | 崇高、压迫、仰视 | 地平线压低 + 垂直体量放大 |
| **深远**（色重晦、意重叠） | 幽深、层层不尽 | 多层重叠山体 + 视线穿透 |
| **平远**（色有明晦、意冲融缥缈） | 冲融、旷远（最合「孤」） | 地平线抬高 + 横向铺展 + 淡墨远去 |

➕ **韩拙《山水纯全集·论山》另提「三远」**，合郭熙共成「六远」：
> 「有近岸广水，旷阔遥山者，谓之**阔远**；有烟雾溟漠，野水隔而仿佛不见者，谓之**迷远**；景物至绝，而微茫缥缈者，谓之**幽远**。」

> 落点示例：《江雪》宜**平远/幽远**（孤舟远、微茫缥缈）；《早发白帝城》起句宜**高远**（白帝城踞山巅、彩云间）。

### 1.2 四时天时（季节/时辰作为独立轴）
郭熙《林泉高致·山水训》原文：
> 「真山水之烟岚，四时不同：**春山澹冶而如笑，夏山苍翠而如滴，秋山明净如妆，冬山惨淡而如睡。**」

> 把「季节」变成可调的山体气质档；《江雪》即「冬山如睡」。（注：「澹冶 / 淡冶」两版本并存；「秋山明净（而）如妆」**版本互异**，有本带「而」、有本不带。）

### 1.3 皴法与墨法（笔墨卡只有「笔法」，缺「皴法」「墨法」谱系）
| 皴法 | 传统归属 | 气质联想 |
|---|---|---|
| 披麻皴 | 董源（元·汤垕《画鉴》「山石作麻皮皴」） | 江南土山、平缓细密、温润 |
| 小斧劈 | 李思训、李唐 | 刚硬、劲挺 |
| 大斧劈 | 马远、夏圭 | 雄浑、磅礴 |
| 卷云皴 | 郭熙 | 云头状山石、流动感 |

➕ **墨分五色**：语出唐·张彦远《历代名画记》「运墨而**五色**具」；通常指焦、浓、重、淡、清（或浓淡干湿黑，加白合称「六彩」）。
墨法：**泼墨**（气势）、**破墨/积墨**（层次）、**焦墨**（枯涩）、**飞白**（「线断意不断」的虚实相生）。

➕ **点苔**：明·唐志契《绘事微言》「画不点苔，山无生气」；恽寿平《南田画跋》喻为「譬之人有眼，通体皆灵……离眼不可也」。→ 提点山石精神的「点睛」层。

### 1.4 ➕ 六法 → 六要（山水画的具体化）
谢赫「六法」是总纲，五代荆浩《笔法记》另立「六要」，更贴山水：
> 「夫画有六要：一曰**气**，二曰**韵**，三曰**思**，四曰**景**，五曰**笔**，六曰**墨**。」

相对六法：**增「墨」**（呼应水墨兴起），以「景」统摄形/彩，以「思」强化构思。→ 可作为画面生成的分层 checklist。

### 1.5 疏密 · 开合 · 呼应 · 势（构图卡的「动态」补充）
- **疏密**：疏处可走马，密处不使透风——直接影响呼吸与节奏。
- **开合**：画面的「进入与退出」路径。
- **呼应 / 势**：画内元素间的动态关系与视觉动势。

> ⚠️ 勘误：「**计白当黑**」出清·邓石如（包世臣《艺舟双楫·述书上》：「字画疏处可使走马，密处不使透风，常**计白以当黑**，奇趣乃出」），**不是笪重光**。
> 笪重光《画筌》的原话是：「虚实相生，**无画处皆成妙境**。」

➕ **边角构图**：南宋**马远「马一角」、夏圭「夏半边」**——取山之一角、水之一涯，留大片空白。→ 与「高留白率」直接相关。

### 1.6 装裱形制——被忽略的「时间性」维度（**本项目高价值**）
| 形制 | 观看方式 | 对动画的启示 |
|---|---|---|
| **手卷** | 由右至左**逐步展开**，边走边看 | 与项目「传统山水以横移换景为主」**完全同构**——手卷就是天然的时间轴 |
| 立轴 | 一瞥整体，向上仰望 | 适合单幅静态定格 |
| 册页 / 扇面 | 近距离、小尺度、把玩 | 适合短制小景 |

> **关键洞察**：项目已确认「横移换景」是传统语法——**手卷的展开节奏可直接作为时间轴卡（卡7）的形制依据**，比借用电影推镜更有学理支撑。

### 1.7 题跋与印章（诗书画印一体）
- 苏轼「**诗画本一律，天工与清新**」确立诗画同源；题跋、钤印与画面共同构成观看内容。
- 对动画的含义：**题诗的位置、字体、节奏**本身就是画面构成的一部分（现项目题诗逐句写就，可视为「题跋」的时间化）。

### 1.8 纸绢与淡彩（「随类赋彩」的边界）
- 谢赫六法第四「随类赋彩」：以色彩**类别关系**影响质感。
- 水墨不等于纯黑白：**纸/绢底色**（米黄、冷灰）、**赭石/花青**淡彩可作低饱和的情感偏色。
- ➕ **没骨法**（不用墨骨勾勒、直接以墨/色点染；传创于徐崇嗣，恽寿平为清初大家）→ 补「写意/工笔」之外的第三种笔调。

## 2. 声 · 声音侧

现有卡片只覆盖**语音韵律**（卡8）。**环境音、音乐、静默整层缺失。**

### 2.1 声景三要素（Schafer，1969/1977）
| 层 | 定义 | 古诗例 |
|---|---|---|
| **基调声** Keynote | 背景性、被忽略的环境声 | 风、水、鸟鸣 |
| **信号声** Signal | 有提示作用的前景声 | 钟声、更鼓 |
| **标志声** Soundmark | 地方特色声 | 「万籁此都寂，但余钟磬音」（常建《题破山寺后禅院》；「都寂」一作「俱寂」，「但余」一作「惟余」） |

> 影视/游戏做法：环境音由 3 层以上叠加，可按「镜头高度」等参数实时调平（如镜头拉高→鸟鸣增、虫鸣减）。

### 2.2 环境音的文化极性（**不可随意配**）
| 声 | 文化联想 | 出处 |
|---|---|---|
| 水声 | 衬幽静 / 表湍急 | 常建《题破山寺后禅院》「万籁此都寂」 |
| 猿啼 | **孤寂、悲**（文化代码） | 《水经注》「猿鸣三声泪沾裳」 |
| 钟磬 / 钟声 | 空灵、禅意 | 常建《题破山寺后禅院》 |
| 鸟鸣 | 生机 | 通例 |

> 落点示例：《江雪》→ 基调声近乎**无**（雪落无声、水声极弱），以「无」表孤寒；《早发白帝城》→ 猿啼（悲）+ 湍水（快）叠加，正是「大欢喜与小悲鸣」的听觉实现。

### 2.3 配器与「声情」（⚠️ 本节已修正）
| 要素 | 情感色彩 | 出处 |
|---|---|---|
| 古琴 | 松沉旷远、孤高岑寂 | 徐上瀛《溪山琴况》**第六况「澹」**：「独琴之为器，焚香静对，不入歌舞场中；琴之为音，孤高岑寂」 |
| 箫 | 幽远、如怨如慕 | 苏轼《前赤壁赋》「如怨如慕，如泣如诉；余音袅袅，不绝如缕」 |
| 琵琶 | 文曲抒情 / 武曲戏剧 | 通例 |

**五声音阶（修正）**：
- ❌ **不要再用**「宫=宽广、商=悲凉…」这套逐音情感对应——**查无可靠古典出处**，属现代通俗说法。
- ✅ 改用《礼记·乐记》论**声情**的原文（可靠）：
  > 「其**哀**心感者，其声噍以杀；其**乐**心感者，其声啴以缓；其**喜**心感者，其声发以散；其**怒**心感者，其声粗以厉；其**敬**心感者，其声直以廉；其**爱**心感者，其声和以柔。」
  → 这给出「**情绪 → 声音形态**」的古典映射（哀=急促低弱、乐=舒缓、喜=发散、怒=粗厉……），比逐音配色更可依据。
- 若仍需调式分工，可仅作**现代设计选择**并标注，不作为古典判据。

### 2.4 静默——声音的「留白」
- 白居易《琵琶行》：「别有幽愁暗恨生，**此时无声胜有声**」——声骤停处的余韵比有声更深。
- ➕ 《老子》**第四十一章**：「大方无隅，大器晚成，**大音希声**，大象无形。」→ 静默是声音的**最高境界**，不只是停顿。
- ➕ 《列子·汤问》「**余音绕梁，三日不绝**」；《礼记·乐记》「壹倡而三叹」（一唱三叹）→ 尾音的**余韵**本身可参数化（衰减时长）。
- 与画面「留白」**同构**：一虚一实、一明一暗的流动节奏。
> 落点：《江雪》末句「独钓」宜留静默；项目已有「句间气口」，可升级为**独立的「静默层」**。

### 2.5 空间与音质（情绪的第二空间）
| 参数 | 效果 |
|---|---|
| 混响 Reverb（长/短） | 长=大厅、余音缭绕；短=贴近、亲密 |
| 音色 Timbre（泛音结构） | 决定「色彩」；偶次谐波听感更谐和 |
| 动态 Dynamics（宽/窄） | 宽=戏剧、宏大；窄=稳定、亲密 |
| 泛音 Overtones | 决定明亮/暗淡 |

### 2.6 吟诵调 vs 朗读（项目当前用 TTS「情感嗓音」，可作对照）
- **吟诵**介于诵读与歌唱之间，依平仄音韵抑扬顿挫；**「平长仄短」**为最重要规律（刘勇刚《论吟诵》）。
- ➕ 其源头可溯至清·徐大椿《乐府传声》：「四声之中，**平声最长，入声最短**。」
- **唐调**（唐文治，1865–1954）「因声求气」：高声诵读、调动气息、揣摩音节。
- ➕ 戏曲曲论可用术语：王骥德《曲律·论腔调第十》论歌之节奏列有「**停声，待拍，偷吹，拽棒，字真，句笃，依腔，贴调**」，论格调有「抑扬顿挫、敦拖呜咽」。
  （⚠️ **归属补注**：此「歌之节奏」八目，《曲律》原文标明系转录**元·燕南芝庵《唱论》**——「元燕南芝庵先生有《唱论》甚详，载《辍耕录》。今采其要。」故原始出处宜记《唱论》。
  另：「声情」作条目名未找到《曲律》直接出处，故只取其**顿挫/停声**术语。）
- **中古音**：中古有入声（短促），普通话已消失，粤语完整保留三套入声韵尾、吴语/闽南语有残留。
> 含义：入声的「顿」在听觉上就是节奏的顿挫——项目语音层已用「入声 0.65×」近似，**学理依据即在此**；若要更「古」，可参考方言入声时长。

## 3. 跨模态 · 声画结合

现有只有「声画同步」（项目已实现严格同步）。**对位、通感、意境整层缺失。**

### 3.1 声画关系三型
| 类型 | 定义 | 情绪效果 |
|---|---|---|
| **同步** | 声画同时且内容一致 | 真实、沉浸（项目现状） |
| **对位** | 声画各自独立、对比反衬 | 产生「第三层意义」，放大张力 |
| **分离** | 声音以画外音出现、声源不在画面内 | 延展空间、制造悬念 |
> 理论来源：爱森斯坦、普多夫金、亚历山大洛夫 1928《关于有声电影宣言》，主张声音作为「脱离视觉形象的独立因素」，借音乐对位法提出「对位式声音」。
> 落点：《江雪》画面极静，可让**声音**承载「独钓」之外的隐忍（对位），而非一味安静。

### 3.2 通感（钱钟书《通感》，1962；收入《七缀集》）
- 感官互借：「红杏枝头春意闹」以**听觉**写视觉的春意。
- 含义：为「以声写色、以色写声」提供古典学理——**画面定「冷」，声音即可定「清冷」**（跨模态映射的合法性依据）。

### 3.3 意境 / 境界（三层理论）
| 理论 | 内容 | 对声画的作用 |
|---|---|---|
| 王国维《人间词话》**有我/无我** | 「以我观物，故物皆著我之色彩」／「以物观物」 | 主观浓、冷热分明／客观淡、冲融 |
| 王国维**造境/写境** | 理想／写实之分 | 决定「写意」还是「写实」 |
| ➕ 王昌龄《诗格》**物境/情境/意境** | 物境偏写景、情境偏抒情、意境主客交融 | 三档递进，可作**分层目标** |
| ➕ 刘禹锡「**境生于象外**」 | 意境在画面之外 | 直接支撑「留白/余韵」 |
| ➕ 宗白华《中国艺术意境之诞生》 | 「意境是情与景（意象）的结晶品」；创构分三层：**直观感相的模写、活跃生命的传达、最高灵境的启示** | 三个可验收的层级 |

> 落点：《江雪》近**无我之境**（以物观物，冷静克制）——这解释了为何不能加表情化元素。

### 3.4 虚实分工
- 笪重光《画筌》：「虚实相生，无画处皆成妙境」；宗白华：「空则灵气往来」。
- 苏轼《书摩诘〈蓝田烟雨图〉》：「味摩诘之诗，**诗中有画**；观摩诘之画，**画中有诗**。」
> 操作：**画面承担「实」，声音承担「虚」**（或反之），一虚一实、一明一暗地流动。

### 3.5 ➕ 赋比兴——「兴」是空镜头的古典依据
朱熹《诗集传》：「**兴**者，先言他物以引起所咏之辞也。」
> 操作：先以自然意象（孤舟、流水、落叶）起兴，再过渡到主体情感——这正是**空镜头起兴**的学理来源，可避免「一上来就抒情」的直白。

### 3.6 ➕ 移情（立普斯）vs 情景交融
- 立普斯（Theodor Lipps, 1851–1914）「移情/Einfühlung」：把自身情感**外射**到无生命之物，使对象仿佛有生命。
- 与中式「情景交融」同向，但移情偏**心理机制**，情景交融偏**天人合一境界**。
> 操作：为「给山石、江水赋予情绪」提供理论许可——但须以「无我之境」克制，否则滑向拟人化图解。

### 3.7 ➕ 互文 / 典故呼应
- 诗中用典（如《江雪》蓑笠→严子陵、《早发白帝城》猿声→《水经注》）可在**配乐主题、画面意象**上呼应，扩展情绪层次。
- 已由 `data/source/context/*/context.json` 的 `allusion_chains` 提供料，**此处只补「怎么用」**。

### 3.8 ➕ 可参数化的视听语言（现代方法论，非古典判据）
- 基本要素（景别、角度、运动、光线、色彩、声音、声画组合）→ 参考 邵清风等《视听语言》（中国传媒大学出版社）。
- 爱森斯坦蒙太奇五法：**度量、节奏、色调、超调性、理性**；其中**节奏蒙太奇**通过镜头交替频率控制情绪紧张度（加快→紧张，放缓→舒缓）。
> 用途：作为「时间轴卡」的现代参数补充；但传统语法优先（手卷 > 电影推镜）。

## 4. 建议实施顺序（按依赖关系，不按重要性）

> 原则（项目既有）：先解决**可度量性**，再**可规模性**，最后**可调优性**。

| 阶段 | 先做 | 理由 |
|---|---|---|
| **① 可度量** | **静默层**（声）+ **声景层**（声）+ 三远轴（图） | 三者都能立刻给出客观量（静默时长占比、环境音层数、地平线位置），可进卡9自检 |
| **② 可规模** | 配器/声情映射、装裱形制→时间轴、皴法/点苔档 | 依赖①的度量闭环；一旦有秤，可按诗批量取值 |
| **③ 可调优** | 声画对位、通感映射、境界（有我/无我）、赋比兴起兴 | 属「天花板」，需前两层稳定后再调，否则易变图解 |
