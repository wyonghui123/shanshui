三轮研究综合 · 高价值优化路线图

把三轮调研（普查 → 核验 → 攻空白）的产出收敛成一张可执行的优化清单：每项都标明解决什么根因、依据哪条模型、成本多少、怎么验证。核心结论一句话：高价值优化不在「再加模型」，而在补齐三个洞——不可度量、不可规模、判据不硬。

00诊断：真正的瓶颈不是「模型不够」

先摆三个数字。它们决定了优化的方向。

58
三轮梳理出的数学模型总数
（二轮 36 + 三轮 22）
<5
真正进入现有链路的模型
（格律 CSP、意象网络、熵、共享隐变量）
2
目前能产出的成品动画数量
且全靠手工

这个落差说明：模型不是稀缺资源，把模型接进链路的能力才是。而接不进去的原因不是懒，是三个结构性障碍：

瓶颈具体表现根因三轮里对应的解法
不可度量 「这个动画好不好」只能靠人看；用户曾反馈「没有看懂这个画」，我们却无法定位是构图、意象还是节奏出的问题 项目没有任何评估层。改进全靠手感，改了也无法判断是变好还是变坏 T19 TIFA 问答式忠实度 + T18 FIFA 时序检查 + 成对盲评
不可规模 每首诗都要人工抽正/负节点、手工排构图。做到第 3 首就会崩 STEP 2 意象层是纯人工；STEP 6 构图是手工调参 T15 TopWORDS-Poetry 格律先验 + C1 NER + C5 可画性门控 + T6 最优传输构图
判据不硬 「负节点」靠人标；镜头时长凭手感；「转」的位置只有一个几何量（曲率） 关键决策缺少可复核、可交叉验证的量化判据 C3 低度节点 + T6 未运输质量（负节点双判据）；T2 Cutting 阶段系数（节奏）；T3 Dramatis 悬念值（转）

由此得到本路线图的第一原则

先做「让一切可比较」的事，再做「让质量变高」的事。没有评估基线，后面所有优化都无法验证——这正是三轮研究攒了 58 个模型却只用了 5 个的根本原因：不是不想接，是接上去也不知道有没有变好。

01优化清单（按价值排序）

8 项优化，按「收益 × 可行性 × 是否解锁后续」排序。每项都能追到具体的模型编号。

O1

评估闭环：给项目装上仪表盘

P0T19 / T18 / T20
解决根因
不可度量。直接回应「没有看懂这个画」——把「看不懂」拆成可定位的失败项（哪个意象没画出来、哪个空间关系反了、哪句顺序错了）。
做法
① 为每首诗自动生成问题集（意象存在性 / 属性 / 空间关系 / 时序）；
② 用 VQA 在动画关键帧上作答，得分 = 通过率；
③ 时序维度用 FIFA 的「时间幻觉」检查（「朝辞白帝 → 暮到江陵」顺序是否画反）；
④ 主观维度用成对盲评 + Bradley–Terry 汇总。
成本
低。无需训练，现成 VQA/LLM 即可；主要工作量在「问题集模板」的设计。
验证
用现有两首动画跑一遍，看分数是否与你的直觉一致。若一致，说明指标有效，可以开始用它指导优化；若不一致，说明问题集需要修——这本身就是有价值的发现。
风险
VQA 对水墨风格（留白、淡墨）的识别率未测；需先做一次小规模校准。
O2

意象抽取半自动化：把「人工抽节点」降级为「人工复核」

P0T15 / C1 / C5 / B2
解决根因
不可规模。这是「只能做两首」的第一道卡口。
做法
① 分词用 TopWORDS-Poetry 的格律先验（比通用分词准，还能识别典故）；
② 意象用 C1 的 Albert-BiLSTM-MHA-CRF 抽名词实体；
③ 歧义用 B2 依存解析消解（「孤舟蓑笠翁」到底是一个还是两个意象）；
④ 可画性门控（C5）前置分流：可画性低的句子直接标记「此句不宜实写，应留白/虚写」。
成本
中。TopWORDS-Poetry 需接入格律模块；依存解析有现成工具（UD-Kanbun / guwencombo）。
验证
拿《江雪》《早发白帝城》当测试集，比对自动结果与人工标注，算准召率。目标不是全自动，是把人工工作量压到「复核」级别。
O3

负节点双判据：把「留白」从手感变成判据

P0C3 + T6
解决根因
判据不硬。负节点（「千山鸟飞绝」的鸟、缺席的人踪）是我们水墨美学的核心，但目前靠人标，无法复核、无法复现。
做法
判据一（网络）：意象共现网络中的低度节点——出现但几乎不与画面元素相连。
判据二（传输）：构图 OT 求解后未被运输的质量（untransported mass）——被诗提及却不该被画出的意象。
两条独立判据交叉验证，一致才判定为负节点。
成本
低。判据一基于已有的 C3 网络；判据二是 O4 的副产品。
验证
在《江雪》上跑，看是否自动标出「鸟」「人踪」，且不误伤「孤舟」「寒江」。
为什么排 P0
这是本项目最有辨识度的一点——把「留白」这个最玄的审美概念，变成两条可计算的判据。它是区别于 Polaca / LivePoem 那种端到端黑箱的核心资产。
O4

构图求解器：用最优传输替掉手工调参

P1T6 / T7
解决根因
不可规模 + 判据不硬。用户反馈「空间上很乱」，根因是构图靠手工试错，没有可求解的目标函数。
做法
意象集合 X → 构图槽位 Y（近景/中景/远景三层）的部分最优传输：
T* = argmin⟨T, C⟩，C = w₁·语义不匹配 + w₂·景深不匹配 + w₃·负节点惩罚
用 Sinkhorn 求熵正则化解；输出每个意象的落位 + 未运输质量。
成本
中。代价矩阵起步阶段用 CLIP 嵌入手工设计，无需标注。
验证
与现有手工构图对比，看是否消除「空间混乱」；并把未运输质量与 O3 的判据一交叉验证。
风险
水墨的「留白」是主动构图语言，OT 的边际约束要显式允许「空槽位」，否则会把画面填满。
O5

节奏实证系数：让镜头时长可解释

P1T2 / T1 / T3
解决根因
判据不硬。目前镜头时长凭手感，无法回答「为什么这个镜头 3.5 秒」——而这恰恰是我们宣称优于黑箱的地方。
做法
① 六弧型结构先验（T1）解决绝句观测点过少导致的过拟合：Ê = λ·E_prior + (1−λ)·E_obs；
② 阶段系数（T2）把起承转合映射到 setup/complication/climax：d_i = d_base·g(stage_i)·(1+α|κ_i|)；
③ 悬念值（T3）给「转」一个语义理由，与曲率 κ 交叉验证。
成本
低。纯参数调整，无需新模型训练。
验证
把当前两首动画的镜头时长代入公式，看回算值是否接近现有人工值。接近 → 说明公式捕捉到了你的直觉，可固化；偏差大 → 说明你的直觉里有公式没有的东西，值得深挖。
O6

句法消歧：补上 STEP 4 的空缺

P1B2
解决根因
判据不硬。STEP 4 目前完全空缺（靠人读），而句法歧义直接决定构图元素的数量与关系。
做法
接入 UD-Kanbun / guwencombo 做依存解析，输出可复核的依存树。
成本
低。工具现成，是 O2 的顺带产出。
验证
「孤舟蓑笠翁」这类歧义句，看解析器给的是「孤舟上的蓑笠翁」还是两个并列意象，与你的判断比对。
O7

三模态共享隐变量（研究轨）

P2T9 / T10 / T11
判断
现在不做端到端训练。三轮确认它「骨架有据、组合自建、无先例可比对」。在没有 O1 评估基线之前启动，会把项目拖进无法判断好坏的调参黑洞。
启动条件
O1 跑通且稳定（有可复现的分数）；有至少 20 首诗的标注数据；否则一律不碰。
如果启动
InfoNCE 三对两两对齐；负样本用「同诗人其他诗作」（Burrows' Delta 挑最像的）逼模型学单首诗的独特性，而非「李白风格」这种粗标签。
O8

编年与作者背景（研究轨，且要退让）

P2T13 / T16
判断
「作者写作背景与经历」是需求第一条，但也是最没有数学模型的一条。
做法
借 Enoch 的范式（特征 + 回归 + 不确定度），但不做年代点估计——中文古诗没有碳十四那种硬标签。退让为「年代区间约束满足」：把用典年代上限、唱和对象生卒、地名建制时间写成不等式，用 CSP 求可行区间。
因果部分只画一张 DAG 写清混淆项（时代、体裁、交游），明确不作因果主张。
价值
诚实比准确更值钱：给出「这首诗作于公元 X–Y 年之间」并说明约束来源，比给一个假精确的年份可信得多。

02三阶段实施顺序

顺序不是按优先级简单排列，而是按依赖关系：后一阶段依赖前一阶段的产出。

阶段一

可度量

目标：让「变好还是变坏」可判断。这是所有后续工作的前置条件。

  • O1 评估闭环 —— 先给现有两首动画建基线分数
  • 产出：问题集模板 + 自动评分脚本 + 两首动画的基线报告
阶段二

可规模

目标：把「人工抽节点、手工构图」变成「自动 + 复核」，从 2 首走向 20 首。

  • O2 意象半自动化（含 O6 句法消歧，是顺带产出）
  • O3 负节点双判据 —— 依赖 O2 的意象输出
  • 产出：一条「输入诗 → 意象表 + 正负节点标注」的自动流水线，人工只做复核
阶段三

可调优

目标：把构图与节奏从「手感」升级为「可求解、可解释」。此时 O1 的分数才能验证优化是否有效。

  • O4 构图求解器 —— 同时产出 O3 的判据二
  • O5 节奏实证系数
  • 产出：用 O1 的分数对比「优化前 / 优化后」，形成可复现的改进记录
研究轨

O7 / O8

与主线并行，但不占用主线资源，且各自有明确的启动条件。

  • O7 启动条件：O1 稳定 + 20 首标注数据
  • O8 启动条件：仅当「作者背景」叙事成为用户可感知的短板时

04明确不做（反推荐）

三轮研究最大的价值，一半在于告诉我们「该做什么」，另一半在于告诉我们「什么不能碰」。

不要做理由
现在做端到端三模态生成没有评估基线、没有数据、不可解释。会把项目从「可解释链路」变成又一个黑箱——而「能回答为什么这个镜头 3.5 秒」正是我们唯一的差异点。
做年代点估计中文古诗没有硬标签，任何点估计都是假精确。退让为「区间约束」才有意义。
声称「经历 → 风格」的因果时代、体裁、交游三重混淆无法消除。只能做准因果描述，并在论文/文档里写明局限。
盲目追 SOTA 生成模型Polaca / CCLAP / ConCLVD / LivePoem 都能生成，但都是黑箱。追它们的画质等于放弃我们的核心优势。
把「留白」当噪声去掉像素级的「时序一致性」（如 Tune-A-Video 的思路）会把留白当成不一致而抹平。留白是构图语言，不是缺陷。

05如果只做三件事

收敛：三个最高杠杆点

  1. O1 评估闭环 —— 它是唯一的「元优化」：让其余所有优化从「凭感觉」变成「可验证」。不做它，后面全是玄学。
  2. O2 意象半自动化 —— 它是从「作品」到「工具」的唯一通道。没有它，项目永远停在两首手工动画。
  3. O3 负节点双判据 —— 它是把「留白」这个最玄的审美概念变成可计算资产的唯一路径，也是本项目区别于所有黑箱方案的核心。

这三件事的共同点：都不需要训练新模型，都能在现有两首动画上立即验证，且互为前置。做完这三件，项目就从「一个漂亮的 demo」变成「一个可测量、可扩展、有独特判据的系统」——这时再谈 O4/O5/O7 才有意义。
