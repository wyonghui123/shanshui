水墨画中人的合理展示方案

以《江雪》蓑笠翁为例，回答一个具体问题：在写意水墨动画里，"人"怎么画才既读得懂、又不破意境。核心矛盾是——放大人物换可读性，代价是"孤"；缩到点景保意境，风险是读成"一坨墨"。

结论先行：走点景尺寸 + 减笔造型 + 墨色分档 + 持竿垂钓 + 舟身微倾，即马远《寒江独钓图》的当代动画化。不放大、不勾线、不加五官。这是一套通用造型语法在《江雪》上的取值——哪些跨诗不变、哪些每诗单独定，见 §7。

研究对象：ink_animations.html 的 #jx-boat / #bd-boat　·　画布 900×600　·　转段推近 0.96→1.12×（v1.3 压平，原 0.93→1.55×）　·　日期 2026-10-02

§1

传统依据：古人怎么处理"人"

这不是审美偏好，是有明确传承的四条硬规矩。它们共同指向一个反直觉的结论——人的可读性来自轮廓特征与姿态，不来自细节。

点景人物：小，且高度概括

山水画通则 · 沈周一路

人物在画面中所占比例很小，却是"画龙点睛，使画面意境毕现"的关键。要点是姿态、动作高度概括（策杖、观瀑、对谈），位置选在视觉焦点。功能是点明主题、增生活气、体现"可游可居"。渔樵人物尤其被视为把现实与意境连起来的关键纽带。

寒江独钓：蓑笠在篷上，人端坐船头

南宋 · 马远《寒江独钓图》

本图是《江雪》意象的直接祖本。画中船篷上搭着蓑衣与斗笠，渔翁端坐船头独钓，全神贯注于漂浮的钓丝；舟身微倾一侧——"既合生活常理，又破平板之局"。除寥寥数笔微波外余皆留白。

减笔：几笔定形，不画五官

南宋 · 梁楷《泼墨仙人》《太白行吟图》

人物置于画面中心，四周大量空白；侧面漫步、口唇微启，靠姿态与气韵传神，衣袍仅"灵动肆意的线条几笔"。面部不作刻画——留白本身就是表情。

水墨动画：似与不似之间

《山水情》1988 · 人物设计吴山明

水墨动画的典范解法。吴山明以简练线条勾人物神韵，抛开比例关系，以"似与不似之间"为造型准则，使人物与氤氲山水融会贯通；背景卓鹤君以泼墨写意造境，靠分层渲染让虚实相生。

四条规矩收敛成一句话：人要做成"可识别的姿态符号"——斗笠的锥与檐负责被认出，前倾的身姿负责传神，墨色的浓淡负责把它从舟上"拎"出来。细节（五官、衣纹、四肢）全部让位给留白。

§5

与现有评估的接口

人物方案不能只谈美感，必须过现有那把"忠实度护栏"（O1）与"留白代理"（O3），否则就是改坏。

必须保持命中的题

JX-E2（exist，expect「孤舟与蓑笠翁」）—— 人舟分离后仍需被认出，不能只剩舟。
全片仅 1 个人物 —— 加竿、加篷都行，不得再添第二个人（"孤"的判据）。
探针 jx-boat @15.5s 可见性 > 0.05 —— 降低舟身墨浓度到 .70 后需重跑确认。

必须守住的上限

留白率 ρ_layout / ρ_render —— 人高 ≤9% 画面高，是这条上限的操作化表达。
O3 正节点 —— 「孤舟」是正节点，不能因降墨浓度跌成负节点。
不要新增"像不像"细粒度题 —— 斗笠锥形这类可由人眼直接判；把它做成题，等于把护栏当目标，正是要避免的。

落地顺序建议：改 #jx-boat → 重跑 node src/o1/o1_run.mjs + node src/o3/o3_run.mjs → 确认 JX-E2 命中、ρ 不降、无回退 → 再把同一套造型规则搬到 #bd-boat。

§6

风险清单

高
可读性 ↔ 意境是零和的。任何"为了让人看清"而放大人物的改动，都会直接稀释"孤"。守尺寸上限是第一纪律。
高
勾线即插画。方案 D（白描）可读性最高，但只要出现连续封闭轮廓线，写意立刻破功、滑向连环画。除非全片统一换语言，否则不采用。
中
动态过强会卡通化。摇橹、回望这类大动作会把水墨的"静"打散。呼吸幅度控制在 ±1px、倾角 ±1° 内。
中
人舟仍可能粘连。若墨色分档不足（舟 .70 / 蓑 .80 只差 10%），在位移滤镜下仍会咬合。必要时把舟再降到 .62，或给蓑衣加纸色飞白拉开边界。
低
蓑笠"移出"人身的语义风险。马远把蓑笠搭在篷上，但我们的 O1 判据把"蓑笠翁"当作一个人。若要还原原作的"蓑笠在篷上"，需确认 JX-E2 仍判命中——建议蓑笠仍画在人身上，篷只作淡墨底。
§7

通用性边界：哪些跨诗不变，哪些每诗单独定

本方案不是一套固定配方，而是「通用语法层 + 每诗取值层」。前者跨诗不变、来自传统；后者随诗而变、由诗句语义驱动。§2–§3 给出的其实是参数化生成器 + 硬边界，《江雪》那版只是它在「孤 + 隐逸 + 钓」这组输入下的一个实例。

§8

落地裁定：《早发白帝城》要不要放人

按 §7 的取值层逐项填。结论：不放人——让「人」以视点在场，而不是以客体在场。

取值《早发白帝城》依据
在场？实体不在场；人 = 第一人称视点O2 意象表 9 行无「人」；「朝辞／还／过」的主语是诗人自己，是叙述者，不是画面客体
角色视点（摄影机即诗人）BD 相机 14.5s「一瞬回望」（cx 452→596→456）——那是「我」回望
尺寸档 / 造型档 / 墨色分档值不适用无实体
动作档交给舟与水轻舟是 focus:true；速度感就是动作的替身
三条理由：① 语义——全诗是「我在舟中看两岸」，人一旦被画进画面，就从视点降格为客体，观众变成「看一个人坐船」而非「我在飞驰」。② 意境——这首的核是轻快·速度·畅快（千里一日还），人的身体带重量与细节，把「轻」往下拽；与《江雪》恰好相反（江雪要「孤」，白帝城要「轻」）。③ 口径——意象表无「人」行、O1 的 33 条 bd 题里 0 条涉及人；若放人只能归为 design 附加（半权重，如芦苇），等于为画面凭空加要素。

注意区分：框架允许放人（会自动归为 design 附加），但这首诗的语义驱动出的取值是 0。不是「绝对不能有」，是「这首不需要有」。反例检验：若坚持放人，最小代价是点景级极小背影，但即便这样也会削弱「轻」，且须登记为 design 附加——不建议。

§9

落地裁定：《静夜思》放不放人（与怎么放）

按 §7 的取值层逐项填。结论：必有人，且是主体——中景、减笔背影剪影、浓墨，动作只有两个：举头 → 低头。

取值《静夜思》依据
在场？必有人——第一人称「我」是唯一在场者O2 意象表：全诗 20 字里「我」是叙述主体；「举头」「低头」是两个由「我」发出的画面动词——不画人，就没有动作可画
角色主体（中景）与《早发白帝城》的「视点在场」相反：那首的人在看在飞（客体不可见，视点即人）；这首的人在做动作（姿态即主体）
尺寸档中景（约 175px / 600px 画幅，近《竹里馆》档）主体须可读；但仍是减笔，不是近景写实
造型档减笔背影剪影（髻 + 头 + 长袍 + 拢袖，无五官）§1 的硬规矩：可读性来自轮廓与姿态。背影把注意力从「他是谁」转向「他在想什么」——思乡不需要脸，也避开五官的插画风险
墨色分档值浓墨剪影（近景逆光，与淡墨月光形成浓淡对照）夜景唯一的重色块；窗棂中墨、明月与霜淡墨——三档分明
动作档举头 → 低头（转/合两句的动词驱动）头（含髻）绕颈枢旋转：转段举头 3s、合段低头 3.5s，镜头几乎不动——姿态就是这首诗的节拍
三条理由：① 语义——「疑是」把霜从实有降为疑似，「思故乡」把故乡留在画面之外；画面里唯一确凿的实体，就是那个举头又低头的人。② 意境——静夜思的核是孤独与乡愁，一个浓墨背影立在月光里，比任何表情都安静；若画正面，反而把「我」变成「他」。③ 对照——与《江雪》同一套旋钮的两个极端：江雪人极小（点景）、动作交给钓竿；静夜思人中景（主体）、动作交给脖颈。与《早发白帝城》则是「实体在场 / 视点在场」的正反两面。

注意区分：背影剪影不是「看不见脸」的偷懒，而是把全部可读性押在轮廓 + 姿态上——髻的高低就是头抬得多高，袍的静立就是不动。反例检验：若画侧面或正面，需引入五官/衣纹细节，滑向插画，且「他在想什么」会被「他长什么样」盖过——不建议。

背影剪影 #sy-figure髻 + 头 + 长袍 + 拢袖（两手拢于背后），四笔浓墨；衣缝线、袖缝线用纸色淡线破开，避免整块墨糊成剪影黑团。已落地
举头 / 低头头组绕颈枢（400,378）旋转：承句低头看霜（+22°）→ 转段 3s 举头望月（-32°）→ 合段 3.5s 低头思乡（+28°）。正 = 低头（髻向前），负 = 举头（髻向后）。已落地
「疑是」的霜月光先从窗内亮起（起句），床前那片「霜」到承句才缓缓定形——因为它是「疑是」，不是实有。已落地
「床前」的榻左下角淡墨榻沿三笔，点在月光落地的位置——床前。已落地
「思故乡」的去向故乡不在画面里。合段唯一的动作是低头，随后全片落入 2s 静默——思乡只在一低头的静默里。已落地
镜头约束（与 §8 同源）：全片 1.00→1.10×，单段峰值速度约 1.7%/s，全片跨度 1.10×——远低于 1.25× 上限，不触发「急推破坏意境」问题。人物的举头/低头由姿态完成，不靠镜头推拉。
