# 水墨画的诗意表达架构

> **范围声明**：本文讨论**水墨画单一通道**，以「更准确地传达诗意」为唯一目标。
> 「文人画」是 20 世纪的学科建构术语，古代的原生表述为士人画、士人笔、士夫画、文人之画；本文一律用「水墨画」指称该通道。
> 相比全链路架构，此处的责任结构发生根本变化：**诗意的传达责任全部落在笔墨与留白上**，没有题跋与音乐分担。这既是劣势，也是聚焦优势——每一项参数都能被直接追责。

---

## 一、目标的定义

### 1.1 诗意不是风格

诗意不等于「画得像诗」或「风格淡雅」。它是一个可分解为三个层次的达标问题：

| 层次 | 判定内容 | 可否由画面直接判定 |
|---|---|---|
| **意象可读** | 诗中的核心物象是否在场且可辨 | ✓ 可判定 |
| **境象可补** | 画面是否提供了超出物象的暗示，允许观者补全 | ✓ 可判定（有量化指标） |
| **余韵可生** | 观者是否产生「言有尽而意无穷」的回味 | ✗ 需人类被试 |

前两层是**生成目标**，第三层是**验收目标**。这与 `理论基础.md` 中 M0–M3 的划分一致：诗意在 M3 位置，只能作验收不可作参数。

### 1.2 诗意的核心机制：离形取神

苏轼《书鄢陵王主簿所画折枝二首》：

> 论画以形似，见与儿童邻。
> 赋诗必此诗，定非知诗人。
> 诗画本一律，天工与清新。
> 谁言一点红，解寄无边春。

**第四句是整套机制的核心**：一枝折枝（局部、截取）承载「无边春」（整体意蕴）。以最少笔墨触发最大补全，这就是水墨诗意可参数化的基本原理——**局部写生＋语义补全**。

配套的是欧阳修《盘车图》诗「古画画意不画形……忘形得意知者寡，不若见诗如见画」，确立「画意不画形」。

> ⚠️ 异文：通行本多作「定**知**非诗人」，四库本作「定**非**知诗人」，引用须注底本。

### 1.3 「不似之似」的两层来源

「不似之似」在明清形成定论，但宋代已有对应的实际表述。通行说法初见于**明·沈颢《画麈》**「似而不似，不似而似」。石涛题诗展开：「名山许游未许画，画必似之山必怪。变幻神奇懵懂间，不似似之当下拜。」

宋代对应的实际表述是**米芾**「意似便已」——「又以山水，古今相师，少有出尘格者，因信笔作之，多烟云掩映，树石不取工细，**意似便已**」（《式古堂书画汇考》卷十三所载米芾自题《云山草笔》语）。本架构以米芾「意似」为宋代锚点，以沈颢、石涛为明清定论。

## 二、诗意的六个参数域

这是本架构的核心。每个域都有原典依据，且都可量化。

### 2.1 墨阶：焦浓重淡清

**文献源头**为唐·张彦远《历代名画记》卷二：

> 运墨而五色具，谓之得意；意在五色，则物象乖矣。

此处「五色」承《周礼·考工记》彩绘之义（青赤黄白黑／玄黄），张彦远原意是**不用五色而以墨运之，五色之效自具**，并以「意在五色」为病（物象乖矣）。因此**张彦远的「五色」是彩绘色的替代，不是墨阶五级**，其语义含排斥彩绘。

后世清人已将二者等同。方薰《山静居画论》：「墨法浓淡，精神变化飞动而已……昔人云墨有五色者也。」董其昌论米芾：「老米画难于混厚，但用**淡墨、浓墨、泼墨、破墨、积墨、焦墨**尽得之矣。」

「焦、浓、重、淡、清」这一固定排序**未溯得确切最早文献**，学界通行解释为清末民初教科书定型，本架构据其通行用法立档。

**参数化**：墨阶 = 含水量梯度，五级。工程落点是灰度分层数与灰度熵。

### 2.2 墨法：破积泼宿飞涨

沈宗骞《芥舟学画编·用墨》给出最完整的操作流程：

> 墨著缣素，笼统一片，是为死墨；浓淡分明，便是活墨。死墨无彩，活墨有光。……法有泼墨、破墨二用。
>
> **破墨者**：先以淡墨勾定轮廓，匡廓既定，乃分凹凸；形体已成，渐次加浓，令墨气淹润，常若湿者，复以**焦墨破其界限**；轮廓或作疏苔于界处。
>
> **泼墨者**：先以土笔约定通幅之局，要使山石林木照映联络，**有一气相通之势**；于交接虚实处，再以淡墨落定，蘸湿墨一气写出；候干，用少淡湿墨笼其浓处。
>
> **南宗多用破墨，北宗多用泼墨，其为光彩淹润则一也。**

积墨：郭熙《林泉高致·画诀》「用淡墨六七加而成深，即墨色滋润而不枯燥」；黄公望《写山水诀》「先用淡墨积至可观处，然后用焦墨、浓墨分出畦径远近」。

宿墨：郭熙「用墨七法」——淡墨、浓墨、焦墨、宿墨、退墨、厨中埃墨、青黛杂墨水。宿墨「自有一种烟雨絪缼之气」。

飞白：书法本原见张怀瓘《书断》。黄宾虹《论用笔》：「笔中有一波三折，成为飞白。飞白之处，细或如沙，粗或如石……**力有不足，间若飞白，成败絮形，即是弱笔，切不可取。**」——这为飞白提供了**负向判据**。

涨墨：明末清初王铎书法原创实践，后经林散之等引入中国画。「润含春雨，干裂秋风」。

**诗性指向**：破＝破界生动；积＝润厚；泼＝气势；宿＝烟雨迷蒙；飞白＝枯涩苍古；涨＝情绪失控与释放。

### 2.3 皴法：十六家与可量化参数

郑绩《梦幻居画学简明·论皴》列「皴分十六家」，核心六种的原始定义：

> **披麻皴**：「如麻披散也……此法始自董北苑，用笔稍纵，笔从左起，转过右收，起笔重著，行笔稍轻，悠扬辗转，收笔复重，笔笔圆运，无扁无方，石形多如象鼻。」
>
> **斧劈皴**：「如铁斧劈木，劈出斧痕也……侧按踢跳，头重尾轻，轮廓随皴交搭，一气呵成……**大斧劈用笔身力，小斧劈用笔嘴力**。」
>
> **折带皴**：「如腰带折转也。用笔要侧，结形要方，层层连叠……**披麻石形尖耸，折带石形方平**……**倪云林最爱画之**。」
>
> **解索皴**：「如解散绳索也……**绳索攀卷之性犹存**也。故长披麻不过悠悠扬扬而已，解索竟自挛挛曲曲矣。**王叔明喜画之**。」
>
> **牛毛皴**：「牛毛法与小披麻无异……**牛毛必用正锋**……必要**渴笔淡墨**，细细密皴，再加**焦墨疏疏醒之**，浓里有淡，淡上见浓，毫丝显然，层次不混。」
>
> **荷叶皴**：「如摘荷覆叶，叶筋下垂也……自上而下，从重而轻，笔笔分歧，四面散放。」

笪重光《画筌》论皴最适合「皴法→气质」的归纳：

> **解索动而麻皮静，烂草质而牛毛文**。
>
> 皴之俯仰，披似风芦，而垂如露草；皴之缜密，明同屋漏，而隐若纱笼……**淡以破浓，聚而随散**。
>
> 虚白为阳，实染为阴。山坳染重，多因阴影相遮；山面皴空，多是阳光远映。

**参数矩阵**：

| 皴法 | 笔速 | 力源 | 干湿 | 疏密 | 线形 | 气质 |
|---|---|---|---|---|---|---|
| 披麻 | 慢、圆运 | 中锋（笔腹） | 淡墨为主 | 中 | 尖耸长线 | 悠扬 |
| 解索 | 慢而屈曲 | 中锋寓侧锋 | 淡、稍润 | 密 | 挛挛曲曲 | 屈厚苍浑 |
| 牛毛 | 极慢、细密 | **正锋（笔尖）** | **渴笔淡墨**＋疏焦 | 极密 | 毫丝显然 | 苍润茂密 |
| 荷叶 | 中慢、悠扬 | 中锋柔 | 上重下轻 | 中疏 | 长秀筋韧 | 秀润绵长 |
| 折带 | 中速、顿挫 | **侧笔** | 干润相间 | 层层叠 | 方平折转 | 方折冷峻 |
| 斧劈 | **速、踢拖** | 侧按（笔身／嘴） | 偏燥、留凿痕 | 中 | 头重尾长 | 峭拔刚硬 |

创制谱系：披麻创于董源；斧劈自李唐而马远、夏圭；折带为倪瓒；解索与牛毛属王蒙；荷叶为赵孟頫／蓝瑛一脉。汤垕《画鉴·唐画》记董源「山石作麻皮皴」。

笪重光自注「诸家各有门庭，勿相混淆。惟通其理而化其偏」——这是本架构把皴法设为不可混用约束的原典依据。

### 2.4 气与骨：四势

荆浩《笔法记》：

> 凡笔有四势，谓筋、肉、骨、气。**笔绝而不断，谓之筋；起伏成实，谓之肉；生死刚正，谓之骨；迹画不败，谓之气。**

另附**墨败诊断规则**，可直接作为渲染质量验收项：

> 故知墨太质者，失其体；色微者，败正气；筋死者，无肉；迹断者，无筋，苟媚者，无骨。

「无形之病」是最接近今人所说的「画之病」：

> 无形之病，气韵俱泯，物象全乖，笔墨虽行，类同死物。

方薰《山静居画论》对「气」的判别最为精准：

> **气韵有笔墨间两种。墨中气韵，人多会得；笔端气韵，世每鲜知。**

这为**「线条质量」独立于「墨色质量」**提供了原典依据。

张彦远论骨气：「形似须全其骨气。骨气形似，皆本于立意而归乎用笔。故工画者多善书。」又论气脉：「一笔而成，气脉通连，隔行不断。」

### 2.5 腕与运：十二参数

石涛《运腕章》穷举运腕状态，这一组几乎可直接做参数表：

> 腕若虚灵，则画能折变；笔如截揭，则形不痴蒙。**腕受实则沉著透彻，腕受虚则飞舞悠扬。腕受正则中直藏锋，腕受仄则欹斜尽致。腕受疾则操纵得势，腕受迟则拱揖有情。腕受化则浑合自然，腕受变则陆离谲怪。腕受奇则神工鬼斧，腕受神则川岳荐灵。**

配套「蒙养／生活」双轴（石涛《笔墨章》）：

> **墨非蒙养不灵，笔非生活不神。**能受蒙养之灵而不解生活之神，是有墨无笔；能受生活之神而不变蒙养之灵，是有笔无墨。

「蒙养」可对应技法训练强度与笔性纯度；「生活」对应自然观察与体验深度。二者缺一即偏枯。

石涛论笔性可穷举：「作书作画，无论老手后学，先以**气胜**得之者，精神灿烂，出之纸上……**笔枯则秀，笔湿则俗**。」

### 2.6 虚实与留白

笪重光《画筌》，画论本体：

> **空本难图，实景清而空景现；神无可绘，真境逼而神境生。位置相戾，有画处多属赘疣；虚实相生，无画处皆成妙境。**

笪重光自注一段是理解留白的钥匙：

> 人但知有画处是画，**不知无画处皆画**。画之空处，全局所关，即虚实相生法。人多不著眼空处，妙在通幅皆灵，故云妙境也。

同书并给出虚实的量化描述：「密致之中，自兼旷远；率易之内，转见便娟」；「山实，虚之以烟霄；山虚，实之以亭台」；「虚白为阳，实染为阴」。

张式《画谭》：「烟云渲染为画中流行之气，故曰空白，非空纸。**空白即画也。**」

留白在画论中的本体语汇是笪重光的「虚实相生」；书法系统的「计白当黑」语出包世臣《艺舟双楫·述书上》所载邓石如语「字面疏处可以走马，密处不使透风，常计白以当黑，奇趣乃出」，可用作近义参照。

## 三、时空参数：三远与四时

### 3.1 三远带色相与气势双参数

郭熙《林泉高致·山水训》不仅给出三远，还给出各自的双参数：

> 山有三远：自山下而仰山颠谓之**高远**；自山前而窥山后谓之**深远**；自近山而望远山谓之**平远**。**高远之色清明，深远之色重晦，平远之色有明有晦。高远之势突兀，深远之意重叠，平远之意冲融而缥缈缈缈。其人物之在三远也，高远者明了，深远者细碎，平远者冲淡。**

> **远山无皴，远水无波，远人无目，非无也，如无耳。**

最后一句尤重要：这是**减笔的量化阈值**——远山不皴、远水不波、远人不目，「非无也，如无耳」。这不是省略细节，而是规定远景的信息上限。

### 3.2 四时带情绪

郭熙：

> 真山水之云气，四时不同：**春融怡，夏蓊郁，秋疎薄，冬黯淡。**
>
> 真山水之烟岚，四时不同：**春山淡冶而如笑，夏山苍翠而如滴，秋山明净而如粧，冬山惨淡而如睡。**

> 春山烟云连绵人欣欣，夏山嘉木繁阴人坦坦，秋山明净摇落人肃肃，冬山昏霾翳塞人寂寂。**看此画令人生此意，如真在此山中，此画之景外意也。**

这是**季节→情绪→观者心理**的完整链条，可直接作为季节轴的判据。

### 3.3 《画意》可画诗句：诗画对应的历史原型

北宋郭熙《林泉高致·画意》收录十七首「先子尝所诵道古人清篇秀句，有发于佳思而可画者」，并说明收录标准含**三种粒度**：「其诗虽全章半句及只一联者咸录之于下」。这是现存最早、最明确的诗画对应选编，其结构正是本架构 D2 意象映射表的历史原型：

| 诗句 | 对应的画面要素 |
|---|---|
| 舍南舍北皆春水，但见群鸥日日来（老杜） | 水口构图、留白、群鸥点缀 |
| 渡水蹇驴只耳直，避风羸仆一肩高（卢雪诗） | 减笔、仆从负重的斜向线条 |
| 行到水穷处，坐看云起时（王摩诘） | 深远、平远、云气留白 |
| 数声离岸橹，几点别州山（魏野） | 极简远景、听觉暗示、极小视觉主体 |
| 远水兼天净，孤城隐雾深（老杜） | 留白率、虚实、孤城小点 |
| 春潮带雨晚来急，野渡无人舟自横（韦应物） | 动态水线、空亭、无人物 |
| 相看临远水，独自上孤舟（郑谷） | 一舟之孤、主体置边缘 |
| 钓罢孤舟系苇梢（无名氏） | 渔父主题、苇草线条 |

其中「远水兼天净，孤城隐雾深」与「数声离岸橹，几点别州山」同本项目《江雪》用例的数量级悬殊结构（千山／一舟）完全同构；「钓罢孤舟系苇梢」「相看临远水，独自上孤舟」与《江雪》的孤舟渔父主题一致。**这十七句可直接作为回归测试集**，验证系统在不同意象密度下的表现。

### 3.4 《画题》十二组：题材维度的骨架

《画意》十七句是诗意维度的横向清单，《画题》十二组是题材维度的纵向骨架，二者互补。十二组为春、夏、秋、冬、晓、晚、松、石、云、烟、水、杂，合计 126 项。

《画题》非原书篇名，乃后世俗称；原文见于《林泉高致集·画诀》末段。

十二组对本项目的价值在于揭示一个既有映射表看不到的事实：**同一物象在不同题材中画法不同**。既有 `class_defaults` 以物象类别给出画法默认值，覆盖的是「物」而非「境」。以「山」为例，在「早春雨景」与「雪后山家」中皴法、墨阶、留白率皆异。

| 夏 | 18 | 0 | 9 | 3 |
| 秋 | 19 | 0 | 7 | 1 |
| 冬 | 15 | 13 | 0 | 1 |
| 晓 | 7 | 1 | 1 | 0 |
| 晚 | 9 | 1 | 1 | 0 |
| 松 | 12 | 0 | 0 | 0 |
| 石 | 7 | 0 | 0 | 1 |

| 杂 | 5 | 0 | 0 | 0 |

**天候频次的分布可直接佐证既有季节档取值**：雪集中于冬组（15 项中 13 项含雪）而夏、秋两组各含雪 0 项；雨集中于夏（9 项）与秋（7 项）而冬组含雨 0 项。此与 `vocab.season` 的 `ink_bias`／`blank_bias` 方向一致。

冬组十五例中九例含「雪」，无一例用皴，与郭熙「远山无皴」及本项目 R10 规则一致；但冬组亦含「雪后山家」「水榭吟风」等有建筑有人的场景，此时山石仍不皴而建筑人物可实写，须区分主体。「绝涧松雪」一例反证：即使松在雪中，雪覆处仍不露松皮皴。

云组四例值得单独注意——**无一是单纯的云朵描写，全是云与山石的关系命题**。「云横谷口」横云隔断谷口以分深远，「云出岩间」云自岩生以分山体，「白云出岫」云在峰上构成层次，「轻云下岭」云在岭下压低山头。即云的全部作用是**改变山石的空间读法**。这补上了本项目 `space` 调制器的盲区：既有表有「云间」→高远、「烟」「雾」→迷远，却无「云横」「云出」这类句法位置的区分。夏组「夏云多奇峰」尤可与「轻云下岭」对读——云不遮山反衬峰高，与云在岭下压低山头作用相反。

水组八例中六例为瀑布（动态水），二例为远水、钓艇（静水），二者在 motion 参数上须分开。「远水鸣榔」一例尤须注意：榔即渔歌，拍节而歌，是听觉混入水画；本项目应拆为「远水」（可画）与「鸣」（不画）。「云溪钓艇」则与《江雪》孤舟主题同族，可入回归集。

**十二组非严格互斥的分类**。原文「秋山晚照」既是秋题也是晚题，「夏山烟晓」既属夏又涉晓与烟，「秋烟晓色」同时入秋、晓、烟三组。故题材组命中后应取各组约束的交集或按权重合并，不可单选。

**松、石两组含画理，非仅题材名**，须区分「题材项」与「画理注」：

松组十二项中前四项（双松、三松、五松、六松）皆为**数量**而非种类，即松题首先关心株数——这是既有映射表完全没有的维度。原文后附郭思自注「思尝见先子作连山一望松，带一望不断之意……前大松作极引望之意」，明言「一望松」是主体处理且松承担引视线作用，与既有 `class_defaults.草木` 的 `role=点缀`（weight 1.0）不符，可作 `composition.space` 增设「引望」软目标的原文依据。

石组是唯一兼含画理者。「怪石之在秋江也，江上蓼花，蒹葭之致，可以映带远近作一二也」是构图法——以江上蓼花蒹葭映带远近，使秋江不空，此为虚实相生的具体做法。「石者，天地之骨也，骨贵坚深而不浅露」（《山水训》）与「专于石则骨露，专于土则肉多」可直接落地为本项目 `stroke_disease` 的新病「骨露」，反向断言为「石骨坚深而不浅露」。此外「林石兼之林木」一条说明石与林可兼画，即皴法与点叶法可叠加，不受「皴法不可混用」约束的绝对限制。

骨架表已建于 `data/source/d2_seed/d2_topic_skeleton.json`，含十二组 `topic_constraint`、15 个物象类别到题材组的映射桥、以及天候复合档提案。合并优先级为 `classes → topic_constraint → word_override`，即题材约束比物象默认更具体，但低于词的特例。

**天候复合档**是十二组带来的第二项结构性发现，且原文统计给出了硬证据：十二组 126 项中明确的复合天候项**逾 20 项**，近五分之一。包括「残雪早春」「雪霁早春」「雨霁早春」（春）、「冬阴霰雪」「风雪平远」（冬）、「夏山雨霁」「夏山雨罢云归」（夏）、「秋山雨霁」「秋风雨霁」「秋风欲雨」（秋）、「雨过晚照」「雪残晚照」（晚）、「烟风晓色」（晓）。而既有 `weather` 为单值档（晴／雨／雪／雾），无法表达。**复合天候是原典常态而非例外**，故单值档属工程简化，须改结构。骨架表提出四组复合档（雪霁、雨霁、雨夹雪、雾霁），各自给出 σ 乘子与留白加成。

**烟组六项中「烟横谷口」与云组「云横谷口」句法完全同构**，可见云烟本为一类而画法分列两目。烟组是十二组中唯一「烟」与季节绑定者（春山烟岚、秋山烟岚两项），故烟的极性随季节变，不可一概判为冷。

**春组的一处冲突须裁定**：骨架表春组 `ink_grade_bias=−1`（墨偏淡），而既有 `vocab.season.春` 的 `ink_bias=0`。二者并非错误，而是题材不同——`season.春` 取郭熙「春山澹冶而如笑」，是已入暖候的明丽之春；骨架表春组据《画题》原文所列「残雪早春」等，是残冬未尽之春。须裁定是拆分「早春／正春」两档，还是令 `season.春` 随题材浮动。

**七项缺口**已登记在骨架表 `known_gaps`：G1 原文补录（已完成）；G2 `weather` 将「烟」映射为「雾」与烟／雾极性相反相悖；G3 松组需写竿法而 `vocab.stroke` 无此法；G4 解索、牛毛、荷叶三皴未入 `vocab.cun`；G5 天候复合档须改结构；G6 春组墨阶冲突待裁定；G7「晚」组 `cun_bias` 误填了 stroke 值待修。

> 「诗是无形画，画是有形诗」一句在《画意》中出现时，郭思明言是「更如**前人言**」，属转述。该语出自北宋张舜民《跋百之诗画》（《全宋诗》卷四九九）。

### 3.5 静气

方薰：「作画不能静，非画者有不静，殆画少静境耳。古人笔下无繁简，对之穆然，思之悠然而神往者，画静也。」

笪重光：「**山川之气本静，笔躁动则静气不生。山林之姿本幽，墨粗疏则幽姿顿减。**」笪注：「画至神妙处，必有静气。盖扫尽纵横余习，无斧凿痕，方于纸墨间静气凝结。」

「静」在画论中是以**排除动态**来定义的。郭熙画诀：「水不潺湲，则谓之死水。云不自在，则谓之冻云。」

## 四、《江雪》全案例：用二十字诗驱动一张水墨

这是本架构最干净的验证案例。全诗二十字只有一个人物，其余全是减法。

> 千山鸟飞绝，万径人踪灭。
> 孤舟蓑笠翁，独钓寒江雪。

### 4.1 「孤」→ 主体—环境比

「千山」（极度广延）与「一舟」（极小点）构成数量级悬殊。转译机制：留白占比大面积不着一笔；构图偏置为主体置于边缘或下方（取深远、平远而非高远）；笔迹密度反差为山石以极淡极虚的点染，与蓑笠翁一处极浓极实的小点形成墨阶断层；全幅不用线描，纯以点笔成形。

### 4.2 「寒」→ 墨值与空间温度

墨分五色的冷灰区：高湿度的淡墨平铺，**用淡墨的湿与静压低全幅明度**。「雪」不是白色，而是**留白本身**——「运墨而五色具」中「白」被列入六彩之一，即**以无代有**。

皴法取**折带**（倪瓒一路）：侧笔顿挫、结形要方、层层连叠，石形方平，气质方折冷峻；不用斧劈（峻、狠、劈砍）。**皴法本身就是情绪参数。**

折带为披麻的变法，二者同属董北苑一系（《梦幻居画学简明》以披麻「始自董北苑」）。本诗意境属寒、寂、孤，与该系的简淡一路相合，历史上的对证是倪瓒折带一路或马夏边角式小景。

### 4.3 「静」→ 运动抑制

全幅运动速度为零：无水纹、无波、无风势。「雪」的垂直降落被完全省略——只画雪「已停」的静场，不画雪的动势。构图上「一」的控制：全幅只有一处「实」（翁），其余皆虚。

### 4.4 诗画同构的心理前提

郭熙《画意》：「然不因静居燕坐，明窗净几，一炷炉香，万虑消沉，则佳句好意，亦看不出，幽情美趣，亦想不成。」

**诗意生成需要「静」的心理前置条件，与笔墨上的静态处理是同构的。** 这条对生成系统有实际意义：若上游的语境解析（`context.json`）未提供静谧的心境层，画面的「静」将无处附着。

## 五、题跋在单通道中的特殊地位

收窄到水墨单通道后，题跋从「画面构成的一部分」升级为**语义的二次生成层**。它有四种机制。

**改写画面语义方向。** 苏轼题鄢陵折枝，把两枝瘦竹幽花释读为「瘦竹如幽人，幽花如处女」——题跋完成从物象到人格的转义，观者按题跋提示重读画面。

**补充画外时空。** 米友仁《潇湘奇观图》自题「夜雨初霁，晓云欲出，其状若此」，董其昌跋称携卷行洞庭舟次，「斜阳篷底，一望空阔，长天云物，怪怪奇奇」。**画面的时间与观看场景由题跋确定，而非由笔墨确定。**

**造成时间层累。** 《潇湘奇观图》卷后有米友仁长题及薛晨羲、葛元喆、吴匏硕、贡师泰、邓宇志、董其昌等宋元明题跋，且画幅与题跋尺幅不同、画幅本身无款。**题跋的层累本身成为作品意义的一部分**，这是「诗书画印一体」在时间维度上的实现。

**印章作为构图收束。** 题款末尾朱印与画面上部红日呼应，使疏朗布局「收到布局疏朗而不失谨严」——**印作为色点与构图锚点**。

题跋与印章在单通道架构中承担了部分诗意传达责任，因此**不是装饰性后缀**，而是语义生成的第二层。

## 六、诗意如何测量

### 6.1 现状：没有现成量表

检索未找到公开发表的「意境量表」正式心理测量学论文。但存在一条可落地的三层拼装路径。

### 6.2 形式层（机器可算，零标注成本）

| 指标 | 定义与依据 |
|---|---|
| `ES_ratio` 留白像素比 | 对 933 幅中国山水画（618–2011，故宫＋中国美术馆）的计算：古画均值 **53.4%**、现代 **32.6%**；**元代达峰 61.7%**（80.3% 该期作品留白占主导）；1960 年代谷值 27.1% |
| `ES_dominant` | 阈值 ES>50% 记为「留白主导」。古画 56.8% 达标，现代仅 9.4% |
| `ES_distribution` | 留白连通域数量、最大空白面积比、留白质心与主体质心的距离 |
| `Ink_levels` | 灰度量化层数、灰度熵、对比度 |
| `Stroke_density`、`Stroke_width_mean/var` | 笔画密度与粗细变化 |
| `Symmetry_local`、`Mass_center_offset` | 局部对称性与视觉重心 |
| `Complexity_index` | 色彩复杂度＋笔画密度−留白 |

留白比例与评价**不是单调正相关**：留白与意境有关，但它同时降低视觉复杂度，且随时代剧烈变动（禅宗、文人戏笔、展厅效应、题材政治化）。因此 `ES_ratio` 以非线性／区间变量入模，其默认值不取单点目标，须取区间并配合意象密度联合约束。

### 6.3 意象层（MLLM＋人工小校验）

`Icon_recognizability` 题材识别置信度；`Icon_density` 意象个数（超过 3 个通常偏叙事化、写实化）；`Schema_accuracy` 典故、时代、技法归属正确率。

### 6.4 情感层（人类被试，七点李克特）

**国画美感五因子语义结构**是目前最接近「意境可测量化」的中文本土实证工作：湛颖等（2019，《中国图象图形学报》14(12):2267-2278）从 511 幅国画＋350 个美感形容词出发，经词汇筛选与因子分析得到**气势、清幽、生机、雅致、萧瑟**五个美感维度；同时用 PAD 连续维度做情感标注，情感分类精度均值 0.68、美感分类最高 0.77。可直接作为指标池。

**歧义度是诗意的核心中介**。Hitsuwari & Nomura（112 名被试）要求分别评分「美感／效价／歧义」，并做 20 秒连续 valence-arousal 报告＋瞳孔测量。结果：**负性情绪下降与歧义下降共同解释美感；瞳孔直径增大独立解释美感**。

因此指标体系必须包含「含混／多义」维度，且预期是**倒 U 型**——完全清晰等于图式化，过于晦涩等于不可解码。这与贡布里希「图式—修正」的平衡是同一原理。

**诗意峦生的生理效标**：Wassiliwizky 等证明诗歌可稳定诱发 piloerection 与眶额皮层／奖赏回路激活，强度与音乐诱发寒颤相当；且**读者自选「有意义」的诗才激活类报酬回路**。可用皮电、HRV、瞳孔作为效标。

**可借用的现成工具**：AESTHEMOS 审美情绪量表（Schindler et al., 2017, PLoS ONE 12(6): e0178899；条目池 75 词，保留 42 题＝21 分量表×2，数据开放于 osf.io/q8zv5）。其俄语版已完成信效度验证（α ≥ 0.70，ΔG = 0.99），**中文版尚无正式信效度报告**，须自行修订与验证。另可用中文版敬畏体验量表 AWE-S-C（Piff 六因子修订版，N=1057）。

**审美效果维度的普适性已被证伪**：Specker et al. (2020, PLoS ONE 15(5): e0232083) 以 14 个 7 点双极量表（warm–cold、heavy–light 等）测量整幅作品与单一线／色的一致性，结果**仅 warm–cold、heavy–light、happy–sad 三维达成显著一致，其余 11 维不一致**，且艺术专业性未产生显著调节。这说明线条与色彩的语义联想**不具跨文化普适性**，因此本架构的形式层指标不得假定「某一笔墨特征必然引发某一情绪」，只能作为被试主观评分的解释变量，而非生成端的硬约束。

### 6.5 诗意合成指数

不要直接加权平均。两步走：

**第一步，潜变量。** 对形式层、意象层、情感层做验证性因子分析，得到二阶因子「诗意／意境」；因子载荷须用专家潜分数做收敛效标。

**第二步，非线性修正。** 将 `ES_ratio` 与 `Ambiguity` 以样条或分箱方式入模，显式建模倒 U；报告边际效应而非单一线性系数。

### 6.6 专家评分的定量方法

**成对比较优于评分。** Bradley-Terry 模型由胜负模式反推每幅画的潜审美分：P(i≻j) = exp(βi) / (exp(βi) + exp(βj))。

**多层BT 更稳健**：对多批标注者或多样式需引入 style 随机效应的层级 BT。

**异质性建模**：若要刻画「懂画的人 vs 不懂画的人」差异，用 Rasch 或混合效应 logistic，把被试随机截距与作品随机截距分离——这同时产出「专家一致性」与「大众共识度」两个可交付指标。

**MLLM 自动评估**：可复用 CII-Bench 的五维评分细则做 1–5 分 rubric（表面信息／审美特征／笔墨技法／文化历史／深层含义）。但**必须报告人类天花板**：CII-Bench 人类 78.2%、最佳模型 64.4%，GPT-4o 在五维上仅 2.71/5，说明模型只停在表层。CII-Bench 自身规模仅 698 图／800 题、深层含义标注主观性强，**只宜作评分细则模板，不宜当金标准**。

### 6.7 最小可行验证设计

**样本** 30–50 幅，跨留白比、跨风格，每幅做约 20 个随机成对比较（覆盖式设计）。

**评价者** 专家 3–5 名（国画或美术理论背景）＋大众 30 名以上（提供跨文化非训练基线）。

**信度门槛** Krippendorff α ≥ 0.67，ICC(2,1) ≥ 0.75。

**效度检验** 收敛（BT 潜分 ↔ 意境共鸣量表分 ↔ 生理 chills）；区分（经典名家 vs 学生习作）；预测（回归验证形式层特征对潜分的解释力）。

**关键反例检验**：必须加入「高留白但图式化」的样本，验证模型不会被单一形式指标骗到。这是防止 `ES_ratio` 失效的必要设计。

| 5 | 远景遵守减笔阈值（远山无皴、远水无波） | M0 生成目标 | 郭熙三远 |
| 6 | 线条质量独立达标（骨肉筋气四势） | M2 验收目标 | 荆浩四势；方薰「笔端气韵世每鲜知」 |
| 7 | 观者产生余韵，且歧义度落在倒 U 区间 | M3 验收目标 | Hitsuwari & Nomura 瞳孔实验 |

**判据 6 的独立性值得单独强调**：方薰指出「墨中气韵人多会得，笔端气韵世每鲜知」，说明线条质量是与墨色质量正交的另一轴。若只检墨色不检线条，会漏掉大量失败样本。

**判据层不可省略。** 形式层指标（`ES_ratio`、`Ink_levels`、`Stroke_density`）只能作回归门禁，用于防止改动造成退化，不能据其判断诗意是否传达成功——留白率与评价并非单调正相关，且线条与色彩的语义联想已被证明不具普适性。语义层指标（`Icon_recognizability`、`Schema_accuracy`）只回答意象是否在场可辨，不回答意境高低。判读层是唯一能判定诗意与余韵是否成立的层。这一分工并非本项目的保守选择：Paint4Poem 的评测中，MirrorGAN 在 IS 与 P@1 上优于 AttnGAN，但人类评测的结论相反，作者明确指出该任务上自动指标与人类判断冲突、需要改进自动评测 [$TRAE_REF](https://arxiv.org/abs/2109.11682)。因此 M3 层判读不可由自动指标替代。

**关于气韵的定位**：气韵与诗意同属 M3，只作验收目标，不作参数。依据是气韵由可学之法产出——郭若虚一面说「必在生知」，一面又说「气韵本乎游心，神彩生于用笔」，沈宗骞则直接说「气韵生动实赖用墨得法」。既然它由笔墨浓淡的具体用法决定，就不存在与之对应的独立旋钮；但它可以被形质指标（线条质量、墨色层次、用墨得当与否）**间接验收**。因此气韵的可实现形态是：把 M2 层可判的形质指标做足，气韵随之成立或随之不成立。

## 八、文献陷阱

以下为水墨理论文献中反复出现、但与原典不符的表述。本架构的立档与引用一律以下述结论为准。

| 通行表述 | 原典实际 |
|---|---|
| 「墨分五色」出自石涛／苦瓜和尚 | 语出**张彦远《历代名画记》**，《画语录》无此语 |
| 张彦远「五色」即墨阶五级 | 张彦远「五色」承《考工记》彩绘义，且含**排斥彩绘**之意（意在五色则物象乖矣），语义已反转 |
| 「焦浓重淡清」有明确最早出处 | **未溯得确证**，通行解释为清末民初教科书定型 |
| 「计白当黑」是画论原生 | 语出**书法**（邓石如语、包世臣记录），绘画本体对应语是笪重光「虚实相生」 |
| 鲜于枢「不似之似」 | **未证实** |
| 司空图「不思安排，风霜自然」 | 已核对《雄浑》原文，**全篇无此语**，疑非出自司空图 |
| 黄庭坚有独立《论画》篇 | **未检索到** |
| 「米氏云山」是米芾自创的名号 | **明代成说**，二米去世百余年后方由董其昌等总结；画迹「稀如星风」，现存代表作多为裱接 |
| 「画山水人物，自名一家」是米芾自述 | 出自**《宋史·米芾传》与蔡肇墓志铭**，是史传与墓志的判断 |
| 王原祁「师法自然」原文 | **未能核实**。相关表述如「王原祁心中无刻不存大痴」实为**黄宾虹的评论** |
| 萧绎《山水松石格》「或离合于破墨」 | 依百科转引，**未直接核验原文** |
| 「文人画」是古代固有术语 | **20 世纪学科建构术语**。古代原生表述为士人画、士人笔、士夫画、文人之画，不得用「文人画」标注古典文本年代 |
| 「南北宗」为董其昌首创 | **非董其昌首创**，莫是龙《画论》已有南北宗之说；文人画概念亦流行于董其昌之前 |
| 张彦远《历代名画记》分九品 | 分**自然、神、妙、精、谨细五等**；九品出自李嗣真《画后品》 |
| 姚最《续画品》建立品级体系 | **无品级体系**。姚最「气韵精灵，未穷生动之致」是拒绝等第化的证据 |
| 谢赫六品是等第化评分 | 六品**评语类型不对称**：一品近乎无言（自认无法品评），三品负面判据最丰富，五六品为技法缺陷清单。品级与评分非线性 |
| 刘勰《文心雕龙》是画论 | 五十篇中**无专论绘画之篇**。刘勰论「文贵形似」而非画之形似，也不谈气韵，不可与谢赫体系并列 |
| 古代「气韵」= 现代「意境」 | **根本不同**。古代气韵含人格伦理维度（郭若虚「人品既已高矣，气韵不得不高」），现代意境是主客体交融的意象系统 |
| 郭若虚主张气韵天生不可学 | 原文是气韵**必在生知、不可巧密得**，但同篇又承认「气韵本乎游心，神彩生于用笔」，沈宗骞亦言「气韵生动实赖用墨得法」。**气韵由可学之法产出，故不能直接参数化，只能由形质指标间接验收**——这是本架构将气韵设为 M3 的依据 |
| 「气韵生动」四字是南齐原句 | 今本多题明人补；钱锺书断为「一曰气韵，生动是也」，原句读存异说，**须以影印本比对**后方可作字面引用 |
| 米氏云山渍染法可配《江雪》 | **谱系不合**。米氏云山属烟云墨戏一路，不在董北苑皴法系内；《江雪》意境属寒寂孤，宜取倪瓒折带或马夏小景 |
| 古代「气韵」可与「品级」挂钩 | **不可**。姚最《续画品》明言「不复区别其优劣，可以意求也」，谢赫六品评语类型亦不对称（高品近乎无言、低品为技法缺陷清单），品级与评分为非线性关系。**品级只能作多维标签，不可量化** |
| 「诗是无形画，画是有形诗」出自郭熙 | 郭熙《画意》明言「更如**前人言**」，是转述。实际出自北宋**张舜民《跋百之诗画》**（《全宋诗》卷四九九），须署张舜民 |
| CCPM 是「古诗—画配对」数据集 | **纯文本**任务（白话描述→四选一选句），27,218 条，**不含任何图像**。适合语义匹配，不适合画通道配对 |
| ACLUE 是诗画资源 | **纯文本古汉语理解基准**，15 个任务，**无任何图像模态** |
| CCPD 与 CCPM 是同一数据集 | 二者不同。CCPD 为 17,103 首、12 类全诗级多标签情感分类，且**未找到官方发布地址** |

## 九、已知边界

本架构有五处结构性限制。

**意境量表须自建。** 意境、诗意、气韵三个构念均无中文心理测量量表——不存在任何由中文母语者样本编制并公开报告信效度的量表。现有中文国画美感研究（湛颖等 2019，从 511 幅与 350 个形容词得气势／清幽／生机／雅致／萧瑟五维）测的是**美感**而非诗意，且未发现公开下载链接。诗意判定式须自行组装并做信效度检验，参照路径见第六章。

**心境层不可由笔墨生成。** 皎然说「静，非如松风不动，乃谓意中之静」——这说明诗意的心境层不可由笔墨参数直接生成，只能通过上游语境层预设。因此 `context.json` 的字段须能承载「静观」类心境，这是硬性接口要求。

**形式层与情感层的联结不可假定。** 线条与色彩的语义联想已被证明不具跨文化普适性（Specker et al. 2020：14 个审美效果维度中仅 warm–cold、heavy–light、happy–sad 三维达成一致，艺术专业性不产生调节）。因此形式层指标只能作为被试主观评分的**解释变量**，不得作为生成端的硬约束。

**皴法无基准可用。** 披麻／斧劈／折带／解索／荷叶等皴法不存在任何公开的图像级或笔迹级标注数据集。现有最高精度仅到 2014 年 150 幅图像、点／线／面三大类、Gabor＋PCA＋SVM，且数据集不公开。皴法量化属本项目的原创工作，也意味着无现成基线可对标，须自建标注规范并公开。

**留白与虚实无标注基准。** 不存在含「留白率」「虚实」结构化标注字段的公开数据集。`ES_ratio` 等指标的参照区间只能自建样本统计，须抓取馆藏图像自行标定。

**意象词典覆盖率不足。** 以《画意》十七句作外层回归实测，现有 `o2_lexicon.json`（88 词）对预期意象的覆盖率仅 **65%**（48 个预期意象中 17 个无条目），缺口集中在三处：动物与人物类不全（无犬、牛、驴、仆，而有猿、蝉、雁、鹤、僧、翁、樵、客）；建筑类缺民居（有亭、楼、寺、桥，无茅屋、村舍）；感官与状态词缺失（无夕阳、石、阴，无春雪、残雨、雪意等过程态）。这意味着未登录词会持续进入人工复核队列，是当前数据侧的主要瓶颈。28 条补充候选已备于 `lexicon_supplement_candidates.json`，但均为推补级，须人工复核后方可并入主表。
