水墨画中古代人物的造型语法 · 通用层

这是 《水墨画中人的合理展示方案》（以《江雪》蓑笠翁为例）的通用层补全。前者回答「这一首怎么画人」；这里回答「换任何诗、任何身份的人，怎么系统地把它定下来」——不是一套到处套的固定配方，而是一台可取值、可回溯、可复核的参数化生成器。

结论先行：古人早已给出三条硬诀——比例诀（丈山尺树，寸马豆人）、简化诀（远人无目……非无也，如无耳）、功能诀（山之人物以标道路，水之渔艇钓竿以足人意）。三条诀加上《芥子园画传》现成的姿态谱，正好凑成四句口诀：身份决定符号，动词决定姿态，景深决定墨色，诗的气质决定尺寸。

依据：王维《山水论》（唐）· 郭熙《林泉高致·山水赋》（北宋）·《芥子园画传》卷四「人物屋宇谱」· 十八描 ·《山水情》(1988)　·　画布参照 900×600　·　日期 2026-10-04　·　上位总纲：山水画 · 水墨画 表达要素总纲（轴2「三远与人物」/ 轴6「点景」）
§1

三条古诀：为什么这样画

这不是审美偏好，是有明确出处的三条硬约束。它们共同指向一个反直觉的结论——人的可读性来自比例、轮廓与姿态，不来自细节。

比例诀 · 人是「分母」

王维《山水论》· 郭熙《林泉高致》

丈山尺树，寸马豆人。
远人无目，远树无枝。

山以丈、树以尺、马以寸、人以豆——人物是整幅尺度的最小单位。这决定了「放大换可读性」在本语法里天然违规：尺寸不是表现手段，是位置声明（我在多远）。

简化诀 · 不是不画，是画成「像没有」

郭熙《林泉高致》

远人无目……
非无也，如无耳。

最要害的是后半句：五官并非不存在，而是画到「像没有」。这正是「留白即表情」的古典出处，也是减笔的合法性来源——简不是省，是把信息压到轮廓。

功能诀 · 人是「功能件」

郭熙《林泉高致》

山之人物，以标道路……
水之渔艇钓竿，以足人意。

人物不是主角，是标路的刻度、点题的引信。另有「道路人塞」——路上该有人，画面才「通」。所以放不放人、放几个，是功能判断，不是美术偏好。

附：三远与人物（郭熙）。「其人物之在三远也，高远者明了，深远者细碎，平远者冲淡；明了者不短，细碎者不长，冲淡者不大。」——人物要随景深改档：高远可稍清楚、深远要碎小、平远要冲淡。这与 D2 的 layer_technique 调制器同构（景深→笔墨档），已落地为人物版的 figure_layer 调制器（d2_techniques.json，见 §8）。
§2

学界把山水点景人物归为四类，与「渔樵耕读」并置，正好覆盖绝大多数诗境。每类只给最少可识别符号——多一个符号，就多一分图解化风险。

§3

姿态式谱：在做什么

《芥子园画传》卷四「人物屋宇谱」已把点景人物整理成现成谱式：点景人物六十二式 · 中号三十二式 · 极小十九式 · 极写意七式。这是一份可"查表"的姿态词典——我们要做的是把式名归一到诗句动词。

（上为节选。原谱另有「极小点景十九式」「极写意七式」——分别对应本方案 §5 的极小档与极写意档。）

归一：诗句动词 → 姿态式

诗句动词对应谱式身体怎么说（可执行要点）
望 / 看 / 临看云式、望山式、临流式、指点式一臂上抬至额（或前伸指），头微仰；重心后移。是「观」不是「动」。
行 / 辞 / 过缓步式、担行囊式、牵马式、负书式整体前倾 3–5°，衣裾后曳；步幅靠倾斜表达，不画双腿交替。
立 / 待负手式、袖手式、倚杖式手拢于背或袖中，不见手；肩线平——「闲」全在手的消失。
坐 / 据坐石式、据石式、独坐式、卧读式身下压，袍裾铺地成一横；重心低而稳。
钓垂竿式、钓鱼式坐姿前倾，一手持竿前伸，竿→丝一线垂下。竿是「钓」的主语，缺竿则动作不成立。
对 / 会对谈式、对酌式、促膝式、两人看云式两人成组、身体微向对方倾——但注意「孤」类诗禁多人（见 §8）。
举头 / 低头（谱外）俯仰式头（含髻/巾）绕颈枢旋转：正角=低头，负角=举头。姿态即节拍，镜头不必动。
抚 / 拈抚松式、把菊式、拈须式一臂伸向所抚之物，指尖即触点；无物可抚时不摆此式。
驱动规则：姿态由诗句动词驱动，不由画师偏好。一首诗只取 1–2 个式；动词缺席（纯写景句）则不给姿态——静立或省人。这与既有方案「动作档由动词定」完全一致。
§4

笔法：怎么下笔

「十八描」是人物衣纹的线描谱系。写意水墨动画只需其中极少数几描——其余（如高古游丝、铁线描）属于工笔/白描语言，一旦引入就把写意拉向插画。

减笔描（主力）

南宋 · 梁楷

《泼墨仙人》《李白行吟图》所用。用笔粗、一气呵成，一笔中有墨色变化；高度概括对象，王瀛称「以少胜多，少许难于多」。这是本语法唯一的主力笔法。

行云流水描（衣纹）

传统十八描之一

表现软而弯转的衣纹，流畅如行云流水。用于长袍/裙裾的少量走向线，交代体积与风向，不勾封闭轮廓。

柳叶描（可选）

传吴道子

两头细、中间粗，虚入虚出。可作为袖口/衣褶的点缀一笔；用多则近白描，慎用。

一条硬护栏：不勾线。凡出现连续封闭的轮廓线（把人的外形一笔圈住），写意立刻破功、滑向连环画。所以笔法只用「块面 + 断线」：身体是墨块，衣纹是断口，边界靠飞白与浓淡拉开，不靠勾边。这条护栏与既有方案 §6「勾线即插画」同源。
§5

四档：多大、多简

芥子园的四层谱式，天然对应四个「尺寸 × 造型」档。这解决了一个关键问题——不是所有人物都该做成点景：主体（如《静夜思》的背影）必须升到中景档，否则读不出「举头/低头」。

档芥子园对应人高 / 画幅造型用途 · 护栏
极写意极写意人物七式≤ 4%一两笔，近乎墨点极远景；只表「有人迹」，不辨身份
极小点景极小点景人物十九式4–6%剪影 + 单一符号远景点景；符号须极准（笠=渔）
点景（默认）点景人物六十二式6–9%减笔：轮廓 + 姿态中景点景；尺寸上限所在档，不得再放大
中号 / 主体中号点景人物三十二式9–30%减笔 + 少量衣纹主体在场（背影/正面）；仍不画五官、不勾线
为什么默认停在「点景」档：尺寸上限是「留白率 ρ 不降」与「孤的强度不稀释」的操作化表达（见既有方案 §3 尺寸守则）。升档只在一种情况下允许——人物是全诗唯一可画的实体与动作主体（如《静夜思》），此时升到中景是语义必需，不是审美选择。
§6

生成器：把语法做成可调参数

下面把这套语法装成一台可交互的参数化生成器：左边是场景，右边是四个旋钮（身份 × 姿态 × 尺寸档 × 墨色）。改任一项，右边读数会同步给出「人高占比」与「取值依据」。注意这不是「要素拼贴」——每类只用一个最少符号，姿态由谱式给骨架，正是为了压低图解化。

§7

取值驱动：从诗到人

「每诗单独定」不等于拍脑袋。下面五条规则把诗句映射到六个取值，每一条都可回溯——这正是既有方案 §7 所说的「取值层」的操作化。

输入（诗句层）输出（人物取值）判据 · 可回溯字段
意象表含人物意象词（蓑笠翁、童子…）在场=1；身份=该词回溯到 O2 意象 id + 词；身份由符号词直取
无人物词，但有第一人称画面动词（举头/低头）在场=1；角色=主体；姿态=俯仰式动词可画 → 人必须在场；否则动作无主语
无人物词，动词是叙述性/位移（朝辞、已过）在场=0；角色=视点主语是「我」但动作在镜头外 → 视点在场（白帝城例）
纯写景，无人称动词在场=0；可留人迹（极写意档）「可游可居」必要时放极小点景，否则省
诗句动词 → 谱式；诗气质 V/A/T + 景深 → 尺寸/墨色姿态档；尺寸档；墨色分档值姿态挂动词；尺寸挂「是否唯一实体」；墨色挂景深与气质
两个要害（沿用既有方案）：① 通用的是「取值规则 + 边界」，不是「这套参数」——把 §6 的一组参数原样搬到别处，就退化成模板化的要素匹配。② 每个取值都要能指回诗句里的一句话（意象词 / 动词 / 气质），否则就是审美主观、无法复核。
§8

与既有系统的接口 · 风险

接口：接到三套既有系统

① O2 意象表 ——「在场/身份」就是意象表的一行；人不是一个新对象，是意象的一类。
② O1 忠实度护栏 —— 存在题（如 JX-E2）必须命中；「孤」类诗全片仅 1 人；探针可见性 > 0.05。
③ O3 留白代理 —— 尺寸档 = ρ 上限的操作化；「孤舟」是正节点，不能因降墨跌成负节点。
④ 与 D2 同构 —— 郭熙「三远与人物」已落地为 figure_layer 调制器（d2_techniques.json）：景深 → 人物尺寸档 / 墨阶，与 layer_technique 并列；词覆盖优先，中号档仅角色=主体可用（§5 护栏已内建）。
⑤ 尺寸档输出 —— resolve_node 现返回人物 size 字段（极写意 / 极小点景 / 点景 / 中号），与四档表一一对应，可被下游动画直接取用。

落地下游：既有三首的取值

本通用层不改变既有裁定，只是给它一个统一出处：
· 《江雪》→ 身份=渔；姿态=垂竿；档=点景（§5 默认档）
· 《早发白帝城》→ 在场=0；角色=视点（规则 3）
· 《静夜思》→ 角色=主体；档=中号；姿态=俯仰（规则 2）
详见 ink_figure_schemes.html §7–§9。

高
可读性 ↔ 意境是零和的。任何「为了让人看清」而升档/放大的改动，都直接稀释「孤」与留白。尺寸上限是第一纪律。
高
符号过载即图解化。给渔翁同时配笠、蓑、竿、鱼篓、水纹……就变成「要素全中」的插图。每类只留最少符号，其余交给留白。
中
勾线即插画。只要外形被连续线描圈住，写意即破功。笔法只用「块面 + 断线」。
中
动态过强会卡通化。行/望/抚的幅度都要极小（倾角 ±1°、位移 ±1px 级）；姿态靠「形」不靠「动」。
低
服饰考据陷阱。身份符号须与诗的语境自洽（唐巾 vs 宋笠 vs 幞头）；考据过细会把减笔拖回写实，得不偿失——符号准即可，形制不求全。
