# 模型卡 · 从诗到水墨动画与语音

> 本文把全链路上每一个「模型」用**同一套卡片模板**介绍一遍。
> 每张卡回答六个问题：**① 它问什么问题 → ② 量纲与量程 → ③ 锚点表 → ④ 用《江雪》实跑 → ⑤ 输出 schema → ⑥ 反例**。
>
> 所有数值均取自项目推演页（`jiangxue_pipeline.html`）与语音脚本（`src/voice/voice_prosody_process.py`）。
> 标 **〔示意〕** 者为展示数据结构与接口形态的示例值，非训练模型的真实推理结果。

---

## 0. 怎么读一张模型卡

定义一个"模型"最容易写废的方式，是堆形容词（"非常悲伤""比较激昂"）——那等于没定义。
**正确做法是：每一维先问一个能用证据回答的问题，再把答案切成档位（锚点）。**

一张合格的锚点表必须满足三条：

1. **判据可观察**：每一档描述的是"文本/画面里能指认的东西"，不是感觉。
2. **档间可分辨**：相邻档有明确分界，且给得出边界例子。
3. **可挂证据**：打分必须附带 `evidence`（引用诗中的字词或画面中的元素）。

## 卡片 1 · 格律模型（STEP 1）

> **一句话**：每个字该念多长？哪里该顿住？

| 项 | 内容 |
|---|---|
| 问的问题 | 这首诗的**音韵骨架**是什么？长短、顿挫、韵脚落在哪 |
| 量纲 | 字级音韵属性（平 / 仄 / 入 / 韵）；韵部；句长；折腰与否 |
| 量程 | 离散类别，**确定性查表**，不依赖任何模型 |

### 锚点表（字长档位）

| 档 | 判据（音韵属性） | 例（《江雪》） | 时长倍率 |
|---|---|---|---|
| **平** | 平声（阴平/阳平），可延长 | 千、山、飞、人、踪、孤、舟、蓑、翁、寒、江 | 1.35 |
| **仄** | 上声 / 去声，收束 | 鸟、万、径、钓 | 0.85 |
| **入** | 入声（塞音尾），短促 | 绝、灭、笠、独、雪 | 0.65 |
| **韵** | 句末韵脚，长且收 | 绝、灭、雪（同属入声屑韵） | 1.65 |

### 实跑（《江雪》）

| 项 | 结果 |
|---|---|
| 句长 | 五言，4 句，共 20 字 |
| 入声密度 | 5 / 20 = **25%** |
| 仄声占比 | **50%**（含入声） |
| 韵脚 | 绝 / 灭 / 雪 —— 全入声屑韵，**促、顿、冷** |
| 体式 | 折腰体 |
| 对下游的约束 | 入声韵基调为"促"→ **禁止舒缓长镜**；句末"仄仄仄"三段收束 → **禁止渐隐结尾，必须顿住** |

### 输出 schema

```json
{
  "poem": "江雪", "form": "五言绝句", "style": "折腰体",
  "chars": [
    { "i": 1, "ch": "千", "tone": "平" },
    { "i": 5, "ch": "绝", "tone": "入", "rhyme": true }
  ],
  "metrics": { "rusheng_ratio": 0.25, "ze_ratio": 0.50, "rhyme_group": "入声·屑" },
  "constraints": ["禁舒缓长镜", "禁渐隐结尾", "句末须顿"]
}
```

### 数据底座：D1 中古音韵书

本卡的「平/仄/入/韵」**不靠模型，靠查表**。该表即 **D1**：

| 文件 | 作用 |
|---|---|
| `d1_rhyme.json` | D1 主表：**字 → 四声(平/上/去/入) + 韵部**；含 `t2s` 繁体归一表 |
| `src/d1/d1_build.py` | 构建脚本（源 → 主表；并入补遗） |
| `src/d1/d1_resolve.py` | 解析器 + 回归校验：韵脚判定、生成 `(字,tone,role)`、与手工标注逐字比对 |
| `src/d1/d1_covcheck.py` | 覆盖率护栏：换源/补遗后重跑，确认不降 |
| `d1_supplement.json` | 补遗层：主表漏收的常用字（人工、有据） |
| `data/source/rhyme/` | 源数据（pingshui-rhyme 0.20 预抓取，MIT） |

**实测（`python src/d1/d1_resolve.py` / `python src/d1/d1_covcheck.py`）**：

| 指标 | 结果 |
|---|---|
| 三首诗 68 字覆盖率 | **100%** |
| 选项命中率（手工平仄 ∈ D1 选项集） | **100%** |
| 自动选读命中（默认取平） | 95.6% |
| 自动选读命中（+「二四六分明」消歧） | **98.5%** |
| 20 首常见近体诗 488 字覆盖率 | **100%** |
| 韵部识别（三首） | 七陽 / 九屑 / 十五刪，**全对**，押韵句均为 1·2·4 |

> **边界**：D1 是「数据」，只给**选项**，不做消歧。兼平仄字（如 望、过、不、思）落在**一三五不论**的奇数位时，格律无法判定，须由语境（`context.json`）或频次先验裁定——这正是 D1 与卡 1 的分工。

### 反例

- **别把入声当"短的仄声"随便处理**：入声是独立韵类（塞音尾），先判入、再判仄。混同会让全诗"促"的基调丢失。
- **别用韵脚位置判押韵**：绝句是 1/2/4 押韵、第 3 句不押。按"每句都押"判会误伤第三句。

## 卡片 2 · 意象与场景图模型（STEP 2）

> **一句话**：诗里**有什么**？更重要的是——**缺什么**？

| 项 | 内容 |
|---|---|
| 问的问题 | 有哪些意象？它们什么关系？哪些是"本该有却没有"的？ |
| 量纲 | 意象多重集 + 关系边 → 场景图 `G_scene`；节点类型 ∈ {实、虚、负节点} |
| 量程 | 节点类型离散；空间层 ∈ {远景, 中景, 近景, 全域} |

### 锚点表（节点类型）

| 类型 | 判据 | 渲染含义 | 例（《江雪》） |
|---|---|---|---|
| **实** | 诗中有明确存在物，可画 | 落成画面元素 | 千山、万径、孤舟、蓑笠翁 |
| **虚** | 有名词但无实体边界 | **承载留白** | 寒江、雪 |
| **负节点** | 被诗提及却"绝/灭" | **不画，但约束留白的面积与连通性** | 鸟（飞绝）、人踪（灭） |

> **虚的两副面孔**：同为「有名词无实体边界」，「雪 / 寒江」是**纯留白**（`role=承载留白`）；而「彩云 / 霜」需**极淡墨湿渲**成形（`role=虚染`，c≈0.06–0.10），并非留白。二者在 D2 中以 `role` 区分。

### 实跑（《江雪》）

| 意象 | 句 | 层 | 文化极性 | 类型 |
|---|---|---|---|---|
| 千山 | 1 | 远景 | 壮阔 · 冷寂 | 实 |
| 鸟（飞绝） | 1 | 远景 | 生机 → 断绝 | **负节点** |
| 万径 | 2 | 中景 | 人世 · 荒芜 | 实（近乎虚写） |
| 人踪（灭） | 2 | 中景 | 人事 → 湮灭 | **负节点** |
| 孤舟 / 蓑笠翁 | 3 | 近景 | 漂泊孤立 / 隐逸渔樵 | 实（焦点） |
| 独钓 | 4 | 近景 | 孤守不屈 | 动作 |
| 寒江 / 雪 | 4 | 中景 / 全域 | 冷寂静 / 洁净覆盖 | 虚（留白） |

**用典链路**：蓑笠 + 独钓 → 渔隐传统边（严子陵钓台 → 《楚辞·渔父》 → 张志和《渔歌子》）。

### 输出 schema

```json
{
  "poem": "江雪",
  "nodes": [
    { "id": "mountain", "text": "千山", "line": 1, "layer": "远景", "kind": "实" },
    { "id": "bird",     "text": "鸟",   "line": 1, "layer": "远景", "kind": "负节点",
      "role": "约束留白面积与连通性" }
  ],
  "edges": [ { "from": "孤舟", "to": "蓑笠翁", "rel": "同景" } ],
  "allusions": [ { "surface": "蓑笠·独钓", "chain": ["严子陵钓台", "楚辞·渔父", "渔歌子"] } ]
}
```

### 数据底座：D2 意象—画法映射表

本卡的「意象类别 → 三远 / 皴法 / 墨色 / 含水 / 笔法 / 层 / 留白 / 点苔」**不靠模型，靠查表 + 调制**。该表即 **D2**（详见 `d2_report.md`）：

| 文件 | 作用 |
|---|---|
| `d2_techniques.json` | D2 主表：**意象类别 → 画法束**（15 类默认 + 词覆盖 + 调制器 + 11 规则） |
| `data/source/d2_seed/painting_theory.json` | 画论来源层（16 条，逐条原文 / 归属 / URL） |
| `data/source/d2_seed/d2_mapping_seed.json` | 人工种子（类别默认 + 词覆盖 + 调制器） |
| `src/d2/d2_build.py` | 构建脚本（合并 + 完整性校验 → 主表） |
| `src/d2/d2_resolve.py` | 解析器：`classify` 落类、`resolve_node` 画法束、`resolve_poem` 诗级 |
| `src/d2/d2_compare.py` | D2 × pipeline 逐项对账（接入前门槛） |
| `src/d2/d2_covcheck.py` | 覆盖率护栏（词 / 中心字 / 节点三层） |

**实测（`python src/d2/d2_resolve.py` / `python src/d2/d2_compare.py` / `python src/d2/d2_covcheck.py`）**：

| 指标 | 结果 |
|---|---|
| 三首 pipeline 逐项对账 | **54 / 54 全一致** |
| 回归校验 | **20 / 20 全通过** |
| 覆盖率（词 88 / 实跑节点 22） | **100%** |

> **边界**：D2 是「桥接数据」，只给**候选集 + 类别档 + 区间约束**；精确数值（ρ、c、扩散参数）由卡 5 构图求解器与卡 6 笔墨物理给出——这正是 D2 与卡 2/5/6 的分工。

### 反例

- **别把"飞绝"当成"有鸟"**：`鸟飞绝` 是**否定性存在**，画上鸟就毁了全诗。这是普通文生图最容易翻车处。
- **别把负节点理解成"没有"**：它恰恰要求"空缺越大、越完整越好"。判据是留白是否**连成大块**，不是"有没有画鸟"这么简单。

## 卡片 3 · 韵味模型（STEP 3）〔示意〕

> **一句话**：这首诗的**气质**是什么？情感藏在字面之外多远？

| 项 | 内容 |
|---|---|
| 问的问题 | 风格画像落在哪些品上？情感与字面的**落差**有多大？ |
| 量纲 | `y ∈ Δ²³`（《二十四诗品》24 维单纯形，L1 稀疏 → 落在 2–4 品）；`ρ` 反差度；`H` 留白熵（bit） |
| 量程 | `y` 各维 ∈ [0,1] 且和为 1；`ρ ∈ [0,1]`；`H ≥ 0` bit |

### 锚点表

**（a）两把尺子**

| 指标 | 低 | 中 | 高 | 含义 |
|---|---|---|---|---|
| 反差度 ρ | < 0.3 | 0.3 – 0.6 | > 0.6 | 情感写在字面上 ↔ 情感完全在字面之外 |
| 留白熵 H | < 1.0 bit | 1.0 – 1.6 | > 1.6 | 字面已说尽 ↔ 字面几乎无情感词 |

**（b）二十四诗品（举四品）**

| 品 | 判据 | 反例 |
|---|---|---|
| 清奇 | 质地**冷峭**、意象疏淡、不落俗艳 | 有雪 ≠ 清奇；雪 + 浓艳才不算 |
| 悲慨 | **孤愤**、有压抑的对抗感 | 单纯的景物凄凉不算 |
| 洗炼 | 字极少而意极足，无赘语 | 字少但意也少，是"空"不是"炼" |
| 含蓄 | 情感**全由缺席与反差**承载 | 有直白情感词就掉档 |

### 实跑（《江雪》）

| 品 | 权重 |
|---|---|
| 清奇 | 0.30 |
| 悲慨 | 0.24 |
| 洗炼 | 0.18 |
| 含蓄 | 0.16 |
| 冲淡 | 0.07 |
| 其余 19 品 | 0.05（合计） |

| 指标 | 值 |
|---|---|
| 反差度 ρ | **0.81**（高） |
| 留白熵 H | **1.94 bit**（高） |
| 通感耦合 | 视觉 → 触觉（寒）/ 听觉（绝、灭的收束音） |

**关键事实**：全诗 20 字中，直接情感词数量为 **0**——没有"悲""愁""苦""恨"，但情感强度极高。这个落差就是"韵味"在数学上的位置：**它住在字面之外**。

### 对生成层的硬约束

ρ 高、H 高 → **画面绝不能"把情感画出来"**。不许低头老人、不许颤抖的手、不许阴沉滤镜。情感必须由**体量的极端对比**（千山万径 ↔ 一舟一翁）和**大面积的空**承担。

### 输出 schema

```json
{
  "poem": "江雪",
  "style": { "清奇": 0.30, "悲慨": 0.24, "洗炼": 0.18, "含蓄": 0.16, "冲淡": 0.07 },
  "rho": 0.81, "H_bits": 1.94,
  "synesthesia": ["视觉→触觉", "视觉→听觉"],
  "constraint": "禁止在画面上直接表现情绪"
}
```

### 反例

- **别被表面意象带偏**：看见"雪"就判"清奇"是最典型的套模板。判据是**质地**（冷峭、疏淡），不是意象名词。
- **别把 24 维当独立维度读**：维度间高度共线，且学界对《二十四诗品》本身是"风格论"还是"意境论"仍有争议。它更适合当**提示性描述**，不适合当回归目标。

## 卡片 4 · 情感模型（STEP 4）〔示意〕

> **一句话**：这句的情绪是**冷暖**、**动静**还是**松紧**？

| 项 | 内容 |
|---|---|
| 问的问题 | 逐句的情绪方向、激活程度、未解决的紧张 |
| 量纲 | `V` 效价、`A` 唤醒、`T` 张力 |
| 量程 | `V ∈ [−1, +1]`；`A ∈ [0, 1]`；`T ∈ [0, 1]` |

### 定义原则：把形容词变成"能回答的问题"

| 维度 | 它问的问题 | 一句话 | 范围 |
|---|---|---|---|
| **V 效价** | 这句的情绪**往外收还是往外扩**？ | **冷暖** | [−1, +1] |
| **A 唤醒** | 这句里**有没有在动的主体、动得多猛**？ | **动静** | [0, 1] |
| **T 张力** | 这句的紧张**被解决了没有**？ | **松紧** | [0, 1] |

### 锚点表

**V 效价（冷暖）**

| 档 | 区间 | 判据（看文本证据，不看意象美不美） | 例 |
|---|---|---|---|
| V1 | −1.0 ~ −0.6 | 指向**丧失/绝灭/死亡**，且无回旋余地 | 鸟飞**绝**、人踪**灭** |
| V2 | −0.6 ~ −0.2 | **冷、孤、萧瑟**，但尚未到绝灭 | **孤**舟蓑笠翁 |
| V3 | −0.2 ~ +0.2 | **纯写景/客观**，无情绪着色 | 两个黄鹂鸣翠柳 |
| V4 | +0.2 ~ +0.6 | **明朗、舒展**，有可喜之物或快意 | 千里江陵**一日还** |
| V5 | +0.6 ~ +1.0 | **明确的欣喜/豪迈**，情绪外放 | **轻舟已过万重山** |

**A 唤醒（动静）**

| 档 | 区间 | 判据 | 例 |
|---|---|---|---|
| A1 | 0.0 ~ 0.2 | **无动作主体**，纯状态/远景 | 千山鸟飞**绝**（"绝"是状态） |
| A2 | 0.2 ~ 0.4 | 有轻微动态但**被抑制**（欲/渐/将） | 万径人踪**灭** |
| A3 | 0.4 ~ 0.6 | **动作主体登场**（哪怕静止） | **孤舟蓑笠翁** |
| A4 | 0.6 ~ 0.8 | 主体**持续动作**，能量上升 | **独钓**寒江雪 |
| A5 | 0.8 ~ 1.0 | **强动作/速度/爆发** | 轻舟**已过**万重山 |

**T 张力（松紧）**

| 档 | 区间 | 判据 | 例 |
|---|---|---|---|
| T1 | 0.0 ~ 0.2 | **已闭合、安顿**，无悬置 | 轻舟**已过**万重山 |
| T2 | 0.2 ~ 0.4 | 平静，略有未言明 | 朝辞白帝彩云间 |
| T3 | 0.4 ~ 0.6 | 出现**对抗或阻隔** | 两岸猿声啼**不住** |
| T4 | 0.6 ~ 0.8 | 主体与环境的**对抗明确** | 孤舟蓑笠翁 |
| T5 | 0.8 ~ 1.0 | **悬置未决、且不释放** | 独钓寒江雪（动作悬在空里） |

### 实跑（《江雪》）

| 句 | 判据落点 | V | A | T |
|---|---|---|---|---|
| 千山鸟飞绝 | V1（绝灭）· A1（无主体）· T2 | −0.42 | 0.22 | 0.30 |
| 万径人踪灭 | V1（绝灭）· A2（抑制）· T2 | −0.55 | 0.18 | 0.38 |
| 孤舟蓑笠翁 | V2（孤冷）· **A3（主体登场）** · **T4（对抗）** | −0.35 | 0.46 | 0.72 |
| 独钓寒江雪 | V2（孤冷）· A4（持续动作）· **T5（不释放）** | −0.48 | 0.71 | 0.95 |

**读这条轨迹**：V 几乎不动（全诗都"冷"），真正在变的是 **A 和 T**。第三句"主体登场"把 A 从 0.18 抬到 0.46，第四句"独钓"把 T 顶到 0.95。

**由轨迹导出的镜头指令**：曲率峰值 **κ = 0.87**（全诗最大），落在句 2→3 之间（空间尺度从 ∞ 阶跃到 1）——**这就是"转"**。
但 κ **只回答"何时推"，不回答"推多猛"**：幅度须另受意境护栏压制（见卡片 7）。

### A 与 T 最容易混——用两首对照

| 句 | V | A | T | 为什么 |
|---|---|---|---|---|
| 轻舟已过万重山 | +0.6 | **0.90** | **0.15** | 极快（A 高），但**问题已解决**（T 低） |
| 独钓寒江雪 | −0.48 | 0.71 | **0.95** | 也在动（A 中高），但**悬着不解决**（T 极高） |

**快 ≠ 紧。**这就是不能用一维"情绪强度"糊过去的原因——A 和 T 在这两句上正好**反向**。

### 输出 schema

```json
{
  "poem": "江雪",
  "lines": [
    {
      "idx": 1, "text": "千山鸟飞绝",
      "V": -0.42, "A": 0.22, "T": 0.30,
      "confidence": 0.8,
      "evidence": ["绝"],
      "anchor": { "V": "V1", "A": "A1", "T": "T2" }
    }
  ],
  "changepoint": { "between": [2, 3], "kappa": 0.87, "note": "尺度阶跃 ∞→1" }
}
```

要求模型**同时报档位（anchor）与分值**：档位是离散判据（可算 κ），分值是连续量（可算相关）。两者不一致时，说明模型没想清楚——这本身就是一条质量信号。

### 反例

- **别把景物属性当情绪**：雪是冷的，但"独钓寒江雪"的冷是**人的孤**，不是温度。按"雪→冷→V 低"判，会把写景诗全判成悲。
- **别把"疑"当悲伤**："疑是地上霜"里的"疑"是**错觉**，不是愁。应判 V ≈ 中性偏负，不能因为"霜"就跳到 V2。
- **别用"名句/好诗"打分**：V/A/T 描述**说话人的情绪状态**，与文学价值无关。量表须明确写"不评价诗的好坏"。

## 卡片 5 · 构图模型（STEP 5）

> **一句话**：东西**摆在哪**？

| 项 | 内容 |
|---|---|
| 问的问题 | 在若干约束下，意象的最优布局是什么？ |
| 量纲 | `ρ` 留白率、`H_blank` 空白连通熵、`E_density` 疏密势能、`g` 视觉重心、地平线高度、负节点硬约束 |
| 量程 | `ρ ∈ [0,1]`；`g ∈ [0,1]²`；地平线 ∈ [0,1]H；负节点 = 硬约束（0/0） |

目标函数：`min E = E_relation + λ₁E_blank + λ₂E_density + λ₃E_balance`

### 锚点表

| 约束 | 低 | 中 | 高 | 例（《江雪》目标） |
|---|---|---|---|---|
| 留白率 ρ | < 0.4（密） | 0.4 – 0.6（一般山水） | 0.72 – 0.85（雪景寒江） | 0.79 |
| 空白连通熵 H_blank | **低 = 大块留白（好）** | — | **高 = 均匀撒开（差）** | 0.41 |
| 视觉重心 g | 居中（呆） | — | 落"三七停"≈ (0.66, 0.68) | (0.65, 0.69) |
| 地平线 | 平远 0.42H | — | 高远 > 0.6H | 0.42H |

### 实跑（《江雪》）

| 约束 | 目标 | 结果 | 判定 |
|---|---|---|---|
| 留白率 ρ | ∈ [0.72, 0.85] | **0.79** | ✓ |
| 空白连通熵 H_blank | 聚成大块 | **0.41** | ✓ 大块留白 |
| 疏密势能 E_density | 势能极小 | **−2.14** | ✓ 收敛 |
| 视觉重心 g | 三七停 (0.66, 0.68) | **(0.65, 0.69)** | ✓ 偏移 0.014 |
| 三远法 | 平远 + 深远 | 地平线 **0.42H** | ✓ |
| 负节点 | 鸟 = 0，人 = 0 | **0 / 0** | ✓ 硬约束满足 |

### 输出 schema

```json
{
  "poem": "江雪",
  "layout": {
    "blank_ratio": 0.79, "blank_entropy": 0.41, "density_potential": -2.14,
    "gravity": [0.65, 0.69], "horizon": 0.42,
    "negative_constraints": { "bird": 0, "human": 0 }
  },
  "regions": [ { "id": "boat", "role": "焦点", "ink": 0.92 } ]
}
```

本卡的**三远候选、留白区间、形制候选、运动语法**取自 D2（`resolve_poem`）：

### 反例

- **留白不是"越高越好"**：判据是**连通**（H_blank 低），不是面积大。均匀撒开的白点面积也大，却是碎白，不成留白。
- **重心不是"越居中越好"**：居中会呆。中国画讲"三七停"，偏心才活。

## 卡片 6 · 笔墨模型（STEP 6）

> **一句话**：每个区域**怎么下笔**？（多湿、多黑、什么笔法）

| 项 | 内容 |
|---|---|
| 问的问题 | 每块区域的含水、墨浓度、笔法；墨在纸上怎么扩散 |
| 量纲 | 含水 `p`、墨浓度 `c`、笔法；扩散半径 `L(t)` |
| 量程 | `c ∈ [0,1]`；含水为档位；`L(t) ∝ t^0.5` |

扩散律：`L(t) = √(γ r cosθ / 2μ · t) ∝ t^0.5` —— **平方根律，不是线性**。
边缘不规则性由纤维噪声掩码控制：`M(x) = Σ P(x, 2ⁱ) / 2^{iH}`。

### 锚点表（含水 × 墨浓度 → 笔法）

| 含水 | 墨浓度 | 笔法 | 例（《江雪》） |
|---|---|---|---|
| 高 | 低（0.12） | 大晕染 · 慢扩散 | 远山 |
| 中 | 极低（0.06） | 枯笔擦 · 近乎不可见 | 万径 |
| 低 | 高（0.92） | 中锋 · 一次落笔 | 孤舟 |
| 低 | 极高（0.95） | 顿笔 · 侧锋 | 蓑笠翁 |
| 极低 | 中（0.40） | 飞白 · 细若游丝 | 钓丝 |
| — | 0 | 不画（留白） | 寒江 / 雪 |

### 实跑（《江雪》）

| 区域 | 含水 | 墨浓度 | 笔法 | 定形时间 |
|---|---|---|---|---|
| 远山 | 高 | 0.12 | 大晕染 · 慢扩散 | 约 8 s 达目标晕幅 |
| 孤舟 | 低 | 0.92 | 中锋 · 一次落笔 | 约 0.6 s 定形，几乎不洇 |

**飞白的生成**：当含墨量低于阈值时，纤维掩码透过笔迹显示，形成断续枯笔痕。钓丝就是这一笔——**全诗最细的墨，也是最不肯断的墨**。

### 输出 schema

```json
{
  "regions": [
    { "id": "far_mountain", "water": "高", "ink": 0.12, "stroke": "大晕染", "diffusion_exp": 0.5 },
    { "id": "fishing_line", "water": "极低", "ink": 0.40, "stroke": "飞白" }
  ],
  "diffusion": { "law": "L(t) ∝ t^0.5", "gamma": 0.42 }
}
```

### 数据底座：D2 意象—画法映射表

本卡的**墨阶、含水、笔法、皴法**按节点取自 D2（`resolve_node`）：

| 本卡字段 | D2 来源 |
|---|---|
| 墨阶 `ink_grade` | 类别基阶 + 层衰减（`layer_atten_steps`）+ 情感位移（V 档 `ink_steps`）；**焦点不衰减**（R4） |
| 含水 `water` | 类别默认 + 词覆盖（如 千山 / 万重山 = 高） |
| 笔法 `stroke` | 类别默认 + 词覆盖（点景·数笔即成 / 斧劈皴·侧锋快扫 / 染（湿渲）…） |
| 皴法 `cun` | 类别默认 + 季节（R10 冬→无皴）+ 词覆盖（万重山→无皴） |

> 完整说明与文件清单见「卡片 2 · 数据底座：D2」。**分工**：D2 给档位与笔法名，本卡给精确 `c`、扩散 `L(t)`、纤维掩码。

### 反例

- **用错幂次一眼就假**：墨在宣纸上是 √t，不是线性。用线性会让晕染"匀速张开"，像水彩不像水墨。
- **飞白不是"虚线"**：它来自"含墨低于阈值时纤维掩码透出"，是物理结果，不是画一排短横线。

## 卡片 7 · 时间轴模型（STEP 7）

> **一句话**：什么时候**动**、什么时候**静**？

| 项 | 内容 |
|---|---|
| 问的问题 | 每段多长、镜头怎么走、留多少静默 |
| 量纲 | 段时长、镜头档、墨浓度、尾部静默；静默预算；相机速度峰值 |
| 量程 | 静默预算 ∈ [15%, 35%]；相机峰值 ≤ 5%/s |

### 锚点表

**（a）静默预算** `ΣΔt_静默 / T_总`

| 档 | 区间 | 判定 |
|---|---|---|
| 偏少 | < 15% | 太赶，无呼吸 |
| **合规** | **15% – 35%** | ✓ |
| 偏多 | > 35% | 太拖，节奏散 |

**（b）镜头档（含意境护栏）**

| 档 | 速度 | 用法 |
|---|---|---|
| 静止 | ≈ 0 | 收束句 |
| 缓移 / 缓推 | < 2%/s | 常态 |
| 缓推近 | 2% – 5%/s | "转"段 |
| **急推** | **> 5%/s** | **禁用**（会把"孤"的偏心构图推没，稀释意境） |

### 实跑（《江雪》）

| 段 | 诗句 | 时长 | 镜头 | 墨浓度 | 尾部静默 |
|---|---|---|---|---|---|
| 起 | 千山鸟飞绝 | 7.0 s | 极远景 · 缓横移 | 0.12 | 1.5 s |
| 承 | 万径人踪灭 | 6.0 s | 极远景 · 轻推远 | 0.06 | 2.0 s |
| 转 | 孤舟蓑笠翁 | 4.0 s | 极缓推近 · 笔触重放 | 0.92 | 0 |
| 合 | 独钓寒江雪 | 8.0 s | 极缓推近（续） | 0.95 | 3.0 s |

| 项 | 值 |
|---|---|
| 总时长 | **25.0 s**（推演设计值） |
| 静默预算 | 6.5 / 25.0 = **26%** ✓ |
| 相机速度包络 | 转段推近方向由 κ = 0.87 定；**幅度受护栏压制**：13–25 s 缓推 0.96→1.12×，峰值 **3.7%/s**（< 5%） |
| 负节点约束 | 全片鸟出现帧数 = 0；除翁外人物 = 0 |
| 禁止项 | 无渐隐结尾（仄仄仄须顿住）；无舒缓长镜（入声基调促） |

### 输出 schema

```json
{
  "T": 25.0,
  "segments": [
    { "name": "起", "line": "千山鸟飞绝", "dur": 7.0, "cam": "极远景·缓横移", "ink": 0.12, "tail_silence": 1.5 }
  ],
  "silence_budget": 0.26,
  "cam_peak": 0.037,
  "forbidden": ["渐隐结尾", "舒缓长镜", "急推"]
}
```

### 反例

- **别按 κ 直接换算推近速度**：κ 只说"何时推"。按它直接换算会过猛，把观者注意力从"空"拉到"物"。
- **别加渐隐结尾**：句末"仄仄仄"三段收束，必须**顿住**。渐隐是消解，与"促、顿"的基调冲突。

## 卡片 8 · 语音韵律模型（参数 → 语音）

> **一句话**：每个字**念多长**？整首**什么情绪**？句子之间**怎么呼吸**？

| 项 | 内容 |
|---|---|
| 问的问题 | 逐字时长、整体情绪色彩、句间衔接 |
| 量纲 | 逐字倍率、情感预设参数、句调曲线、停顿预算、气口 |
| 量程 | 倍率 > 0；`dur_scale` 越 > 1 越慢；`range_k` 越 > 1 音域越宽 |

### 锚点表

**（a）逐字时长倍率（来自卡片 1 的格律）**

| 档 | 倍率 | 依据 |
|---|---|---|
| 平 | 1.35 | 平长 |
| 仄 | 0.85 | 仄短 |
| 入 | 0.65 | 入促 |
| 韵 | 1.65 | 韵长且收 |

**（b）情感预设（三首各一套）**

| 预设 | 诗 | 语速 | 音高 | 音域 | 气声 | 句调 |
|---|---|---|---|---|---|---|
| `sad_longing` 悲伤·思念 | 静夜思 | 1.11（放慢） | 0.93（降） | 0.72（压窄） | 0.55 | 再下沉 −0.7%/s |
| `cold_lonely` 清冷·孤寂 | 江雪 | **1.16（最慢）** | **0.90（最低）** | **0.66（最窄）** | **0.60（最重）** | 再下沉 −0.8%/s |
| `joyful_swift` 轻快·畅意 | 早发白帝城 | **0.94（略快）** | **1.06（略高）** | **1.12（展宽）** | **0.34（很轻）** | 再上扬 +0.6%/s |

### 关键机制（三项）

1. **连续时间规整**：先取逐字理想倍率 → 沿时间做高斯平滑（**σ = 45 ms**）→ 整体归一（保总时长）。
   早期"逐字硬伸缩"会让字间语速瞬间跳变（最大 2.5×），听感就是"**一字一顿**"——已修复。
2. **句调曲线**：起（中平微降）→ 承（低抑下降）→ 转（上扬）→ 合（深降渐弱）。
3. **句间呼吸**：气口 170 ms（400–3000 Hz 带通吸气噪声）、句首 250 ms 对数滑音接前句尾音、按韵脚长短自动补停顿（韵脚越短补越多）。

### 实跑（三首）

| 诗 | 预设 | 配音时长 |
|---|---|---|
| 江雪 | cold_lonely | 19.578 s |
| 早发白帝城 | joyful_swift | 13.631 s |
| 静夜思 | sad_longing | 18.187 s |

### 输出 schema

```json
{
  "poem": "江雪", "voice": "zh-CN-YunjianNeural",
  "preset": "cold_lonely",
  "warp": { "mode": "smooth", "sigma_ms": 45, "match_duration": true },
  "per_char_ratio": { "平": 1.35, "仄": 0.85, "入": 0.65, "韵": 1.65 },
  "lines": [ { "idx": 1, "start": 0.2, "end": 2.73 } ],
  "pause_budget": { "min": 0.70, "max": 2.40 }
}
```

### 反例

- **别用"逐字独立伸缩"**：字间语速跳变会造成"一字一顿"，必须连续规整。
- **别把参数写反**：`dur_scale` 是"整体时长倍率"，越大越慢。写反会让"放慢"变成"加速"（项目里踩过这个坑）。

## 卡片 9 · 一致性自检模型（STEP 8）

> **一句话**：**出厂合格吗**？

| 项 | 内容 |
|---|---|
| 问的问题 | 各层参数是否自洽？有无违反硬约束？ |
| 量纲 | 各项度量 + 阈值 |

### 锚点表（阈值即判据）

| 检查项 | 度量 | 阈值 |
|---|---|---|
| 情感一致性 | ECE = d(y_text, ŷ_paint) | < 0.15 |
| 韵律—运动耦合 | corr(仄声位置, 运动能量) | > 0.45 |
| 笔墨物理性 | 扩散半径是否服从 t^0.5 | R² 高 |
| 留白约束 | ρ | ∈ [0.72, 0.85] |
| 静默预算 | ΣΔt_静默 / T_总 | ∈ [15%, 35%] |
| 负节点约束 | 鸟 / 人出现 | 0 / 0 |
| 史实挂源 | 有出处的背景论断占比 | 高（幻觉率低） |

### 实跑（《江雪》）

| 检查项 | 结果 | 判定 |
|---|---|---|
| 情感一致性 ECE | 0.09 | ✓ |
| 韵律—运动耦合 | 0.63 | ✓ |
| 笔墨物理性 R² | 0.97 | ✓ |
| 留白率 ρ | 0.79 | ✓ |
| 静默预算 | 26% | ✓ |
| 负节点 | 0 / 0 | ✓ |
| 史实挂源 | 3 / 3 | ✓ 幻觉率 0% |

### 输出 schema

```json
{
  "poem": "江雪",
  "checks": [
    { "id": "emotion_consistency", "metric": "ECE", "value": 0.09, "threshold": "<0.15", "pass": true }

}
```

### 反例

- **别把"通过率"当"质量分"**：自检是**护栏**，只回答"有没有画错/违反约束"，不回答"画得好不好"。100% 通过 ≠ 意境好。

## 附录 C · 三条通用反例

1. **堆形容词 = 没定义**。锚点必须是可观察的判据。
2. **档间无边界例子 = 没法判**。每档至少给一个正例、一个易混反例。
3. **不挂证据 = 不可核**。任何打分都必须能指回诗中字词或画面元素。
